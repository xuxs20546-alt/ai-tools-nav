工具简介

Kensho 是一家成立于 2013 年的 AI 数据分析公司，总部位于美国马萨诸塞州剑桥市。2018 年 3 月，S&P Global（标普全球）以约 5.5 亿美元收购了 Kensho，将其作为集团内部的 AI 核心引擎。Kensho 最初以金融市场的预测分析闻名——它能够用自然语言回答复杂的金融问题，例如"油价每上涨 10 美元，哪些行业的股票表现最好？"——这类查询在传统金融终端中需要数小时的数据挖掘，而 Kensho 可在数秒内完成。

在被 S&P Global 收购后，Kensho 的产品定位从独立分析工具逐步转变为 S&P Global 数据生态的 AI 层。其最新的核心产品包括 Kensho Agents——一套连接大语言模型与 S&P Global 专有数据的 AI 代理工具，以及 S&P Global Plugin——允许 AI 应用直接检索标普全球的金融数据和分析。Kensho 的技术栈还涵盖自然语言处理、知识图谱构建和机器学习预测建模。

核心功能

Kensho Agents / Agent Skills：这是 Kensho 面向 AI 时代的最新产品。它将 S&P Global 的海量金融数据（公司财务、行业分析、市场数据、ESG 评分等）封装为预构建的 AI "技能"，开发者可以直接将这些技能集成到自己的 LLM 应用中，实现用自然语言查询 S&P Global 的专业数据库。每个技能针对特定数据域（如公司基本面、供应链关系、ESG 指标）进行了优化。

S&P Global Plugin：面向 ChatGPT、Claude 等主流 AI 平台的官方插件，安装后用户可以在对话中直接查询 S&P Global 的金融数据。例如在 ChatGPT 中问"苹果公司过去五年的收入增长趋势"即可获得带有源引用的数据答案，而不是 AI 的"幻觉"回复。

自然语言金融分析（NLP Analytics）：Kensho 早期成名的核心能力——用户输入自然语言问题，系统自动将其翻译为结构化查询、在 S&P Global 数据库中检索、运行统计模型并返回可视化图表和分析文本。例如"对比 FAANG 公司过去三年的研发支出占收入比例"这样的复杂问题，Kensho 可以自动拆解、执行并生成对比图表。

知识图谱与关联分析：Kensho 构建了全球上市公司之间的供应链、投资、竞争和客户关系图谱，可以自动发现"某供应商的突发事件可能影响哪些下游公司"这类隐藏的关联风险。

上手体验

Kensho 目前主要通过 S&P Global 的企业平台（Capital IQ Pro）和 API 向机构客户提供，个人用户无法直接注册使用。对于已获得权限的机构用户，Kensho 的功能以"模块"形式嵌入在 S&P Global 的现有产品中。例如在 Capital IQ Pro 的搜索框中可以直接输入自然语言问题触发 Kensho 分析引擎。Agent Skills 和 Plugin 则面向开发者，通过 S&P Global 的开发者门户注册并获取 API 密钥后即可调用。文档和技术支持体系完善，但上手仍需要一定的金融数据知识和 API 集成经验。

优点与局限

优点：背靠 S&P Global 的海量优质金融数据，数据权威性和覆盖面在行业里无可匹敌；自然语言分析能力经过多年打磨，在回答复杂金融问题时准确率远高于通用大模型；Agent Skills 的模块化设计使 AI 开发者可以按需调用，无需处理底层数据清洗和验证；知识图谱的关联分析能力在风险管理和供应链尽职调查中具有独特价值。

局限：不面向个人用户开放，中小企业和独立研究者几乎无法直接使用；定价不透明且门槛极高，只有大型机构能负担；功能深度绑定 S&P Global 生态，离开该生态后数据价值大幅下降；对中文市场的覆盖有限，主要服务于英语金融圈。

常见问题

Q: Kensho 和 ChatGPT 有什么区别？
A: ChatGPT 是通用大语言模型，它的金融知识来自训练数据且可能过时或产生幻觉。Kensho 则连接到 S&P Global 的实时专业数据库，回答有明确的数据来源和时效性保证，更适合严肃的金融分析场景。

Q: 个人投资者能使用 Kensho 吗？
A: 目前不能。Kensho 作为 S&P Global 的企业级产品，只向机构客户开放。个人投资者如果需要类似功能，可以考虑 Kavout、YCharts 等面向个人用户的产品。

Q: Kensho Agents 是什么？
A: 是 Kensho 推出的面向 AI 开发者的工具集，将 S&P Global 的数据封装成可复用的 AI 技能模块，开发者可以在自己的 LLM 应用（如 LangChain、AutoGPT）中调用这些技能来获取准确的金融数据。
