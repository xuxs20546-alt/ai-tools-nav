Überblick

Amazon CodeWhisperer ist ein KI-Pair-Programming-Assistent von Amazon Web Services (AWS). Er wurde im Juni 2022 erstmals als Vorschau vorgestellt und im Juni 2023 offiziell eingeführt. Wenn Entwickler Kommentare schreiben oder wenige Codezeilen eingeben, vervollständigt er automatisch ganze Funktionen und Logik. Er unterstützt gängige Sprachen wie Python, Java, JavaScript, TypeScript, Go und Rust und liefert für AWS-Dienste wie Lambda, S3 und EC2 Code-Vorschläge, die sich an Best Practices orientieren. Am 30. April 2024 führte AWS CodeWhisperer in die Marke Amazon Q Developer über; die ursprüngliche kostenlose Stufe und das Pro-Abonnement bestehen bis heute fort. Für Entwickler im AWS-Ökosystem ist er seit langem die wichtigste kostenlose Alternative zu GitHub Copilot und ein typisches Beispiel für einen „selbst entwickelten Programmierassistenten eines Cloud-Anbieters".

Kernfunktionen

Erstens: automatische Code-Vervollständigung. Entwickler müssen nur einen Funktionsnamen oder einen Kommentar schreiben, und CodeWhisperer generiert auf Basis des Kontexts den vollständigen Funktionsrumpf. IDE-Plugins decken VS Code, die gesamte JetBrains-Familie, Visual Studio und das AWS-eigene Cloud9 ab; Vorschläge werden einfach mit der Tab-Taste angenommen.

Zweitens: tiefe Integration in AWS-Dienste. CodeWhisperer wurde speziell für AWS-API-Aufrufe trainiert – etwa bei Lambda-Funktionen, S3-Lese- und Schreibvorgängen oder IAM-Richtlinien orientieren sich die Vorschläge an den offiziellen AWS-Best Practices. Das ist der deutlichste Unterschied zu allgemeinen Programmierassistenten.

Drittens: Sicherheitsscans. Es scannt Code auf gängige Schwachstellenmuster wie Injection-Risiken, hartcodierte Schlüssel und schwache Verschlüsselungsalgorithmen und gibt konkrete Behebungsvorschläge. Diese Funktion steht bereits in der kostenlosen Stufe zur Verfügung – ein seltenes Unterscheidungsmerkmal unter ähnlichen Tools.

Viertens: Referenzverfolgung und Compliance-Hinweise. Wenn generierter Code auf Open-Source-Projekte verweist, zeigt das Tool die entsprechenden Lizenzinformationen an, sodass Teams Quellen bei Compliance-Prüfungen leicht nachvollziehen können.

Fünftens: Befehlszeilen-Szenarien. Seit November 2023 bietet AWS CodeWhisperer for command line an (inzwischen in Amazon Q Developer CLI übergegangen), sodass Entwickler im Terminal per natürlicher Sprache Skripte schreiben oder Logs untersuchen lassen können.

Erste Schritte

Für die erste Nutzung ist ein AWS-Konto erforderlich. Die kostenlose Stufe steht privaten Entwicklern vollständig offen – ohne Angabe einer Zahlungsmethode. Die Installation ist unkompliziert: Plugin im VS-Code- oder JetBrains-Marktplatz suchen und installieren, sich mit AWS Builder ID oder IAM Identity Center anmelden, und schon ist das Plugin im Editor aktiv.

Der tägliche Ablauf ist im Grunde: Kommentar schreiben oder Funktionssignatur eingeben, auf den grauen Vorschlag warten, mit Tab annehmen oder mit Esc verwerfen. Falls Vorschläge zu sehr stören, kann man die automatischen Vorschläge in den Einstellungen deaktivieren und sie per Tastenkürzel manuell auslösen. Bei AWS-bezogenem Code sollte die Sicherheitsscan-Option aktiviert bleiben – sie ist eine zusätzliche Prüfung vor dem Commit.

Eine beachtenswerte Änderung: Nach der Umbenennung 2024 migriert das alte CodeWhisperer-Plugin automatisch zu Amazon Q Developer; Menüs und Einstellungen tragen die neue Marke, die Bedienlogik bleibt aber im Wesentlichen gleich. Insgesamt dauert es meist nur etwa zehn bis fünfzehn Minuten von der Installation bis zum ersten brauchbaren Vorschlag.

Vorteile und Nachteile

Vorteile: Die kostenlose Stufe ist für private Entwickler vollständig offen – keine Einstiegskosten. Die enge Anbindung an AWS-Dienste liefert qualitativ hochwertige Vorschläge für die Cloud-Entwicklung. Sicherheitsscans und Lizenzhinweise sind klare Pluspunkte und praktisch für compliance-orientierte Teams.

Nachteile: Für Teams, die AWS gar nicht nutzen, sind die Vorteile kaum spürbar, und die tägliche Vervollständigungsqualität bleibt hinter reifen Produkten wie GitHub Copilot zurück. Nach der Umbenennung in Q Developer ist die Produktlinie komplexer geworden, und Einsteiger verlieren leicht den Überblick zwischen kostenloser Stufe, Pro und den verschiedenen Kontingentbeschreibungen. Fortgeschrittene Befehlszeilenfunktionen setzen etwas AWS-Erfahrung voraus.

Für wen geeignet

  • Einzelne Ingenieure und Teams, die mit AWS-Cloud-Diensten entwickeln;
  • Einsteiger, die einen KI-Programmierassistenten kostenlos ausprobieren möchten;
  • Entwickler mit Bedarf an Code-Sicherheitsscans;
  • Entwickler, die bereits die AWS-IDE-Toolchain (Cloud9 usw.) nutzen.

Häufige Fragen

Heißt CodeWhisperer heute noch so? Seit April 2024 heißt es Amazon Q Developer; alte Plugins migrieren automatisch, die Funktionen bleiben erhalten.

Reicht die kostenlose Stufe? Für die tägliche Vervollständigung und Sicherheitsscans privater Entwickler meist ja; Pro lohnt sich, wenn Teamverwaltung oder höhere Kontingente benötigt werden.

Welche Entwicklungsumgebungen werden unterstützt? VS Code, die JetBrains-Familie, Visual Studio und AWS Cloud9 verfügen über Plugin-Unterstützung.

Kann es zusammen mit GitHub Copilot installiert werden? Technisch ja, aber gleichzeitige automatische Vorschläge stören sich leicht gegenseitig – besser nur eines aktivieren.
