Tool-Überblick

Continue ist ein Open-Source-KI-Programmierassistent, der als Plugin für VS Code und JetBrains läuft und Entwicklern Chat, Codevervollständigung und automatische Bearbeitung direkt im Editor bietet. Sein größtes Merkmal ist die „Modellfreiheit“: Er ist an keinen einzelnen Anbieter gebunden, unterstützt Cloud-Modelle von OpenAI, Anthropic, Google u. a. und kann über Ollama und llama.cpp auch lokale Modelle sowie interne oder selbst gehostete Dienste anbinden. Das Projekt wird als Open Source mit öffentlichem Repository veröffentlicht, sodass Entwickler den Code selbst prüfen, ändern und bereitstellen können – besonders beliebt bei Teams, die Wert auf Privatsphäre und Datenkontrolle legen. Die offene Lizenz und das öffentliche Repository machen es zudem zu einer gängigen Referenzimplementierung für die Erforschung von KI-Programmierassistenten. 2025–2026 wurde Continue vom KI-Code-Editor Cursor übernommen; das Projekt veröffentlichte die finale Version 2.0.0, entfernte Telemetrie, und das Team wechselte zu Cursor, um dort weiterzuarbeiten.

Kernfunktionen

Erstens: Chat im Editor. Wählen Sie Code in VS Code oder JetBrains aus und stellen Sie Fragen – Code erklären, potenzielle Probleme aufzeigen, Refactoring-Vorschläge geben. Die Antworten der KI basieren direkt auf dem Kontext des aktuellen Projekts.

Zweitens: Codevervollständigung. Beim Tippen erscheinen automatisch Vorschläge; verschiedene Vervollständigungsmodelle können konfiguriert werden. Lokale Modelle arbeiten komplett offline und erfüllen so die Anforderungen von Offline- oder sensiblen Umgebungen.

Drittens: Automatische Bearbeitung und Agentenmodus. Wählen Sie Code aus und beschreiben Sie das Ziel in natürlicher Sprache (z. B. „Ändere das in eine asynchrone Implementierung“) – die KI wendet die Änderung direkt im Editor an; neuere Versionen unterstützen zudem einen Agent-Modus für mehrstufige Entwicklungsaufgaben.

Viertens: Anpassung und Programmierbarkeit. Nutzer können eigene Prompt-Vorlagen und benutzerdefinierte Befehle schreiben und sogar teilbare benutzerdefinierte Agents erstellen, um die Entwicklungsstandards des Teams im Tool zu verankern.

Fünftens: CI-Integration. Continue 2.0 kann KI-Prüfregeln in den CI-Prozess einbinden, sodass Teams vor dem Zusammenführen von Code automatisch KI-Reviews ausführen – Regeln im Code werden so in der CI erzwungen.

Erste Schritte

Suchen Sie Continue im VS-Code-Erweiterungsmarktplatz und installieren Sie es, oder installieren Sie es über den JetBrains-Plugin-Marktplatz; nach einem Neustart erscheint das Continue-Panel in der Seitenleiste. Beim ersten Start muss ein Modell konfiguriert werden: Am einfachsten ist ein OpenAI-kompatibler API-Schlüssel; datenschutzbewusste Entwickler installieren Ollama und wählen ein lokales Modell – in wenigen Minuten läuft alles.

Typischer Ablauf: Projekt öffnen → Code auswählen → im Panel fragen oder erklären lassen → mit „Edit“ die KI den Code direkt ändern lassen → Diff prüfen und übernehmen. Mit konfigurierten Regeln folgen die Antworten automatisch den Teamstandards wie Codestil und Namenskonventionen.

Da Continue quelloffen ist und viele Optionen bietet, ist die Lernkurve etwas steiler als bei kommerziellen Assistenten: Die erste Modellkonfiguration und das Verständnis der .continuerc-Datei erfordern etwas Geduld, bieten dafür aber maximale Flexibilität. Die neuesten Entwicklungen nach der Übernahme finden Sie in den offiziellen Dokumenten und Repository-Ankündigungen. Im Team lassen sich Konfigurationsdatei und Regeln ins Repository einchecken – neue Mitglieder erhalten nach dem Klonen sofort konsistentes Tool-Verhalten.

Vorteile und Grenzen

Vorteile: Vollständig Open Source mit transparentem Code, selbst hostbar und starke Datenkontrolle; freie Modellwahl – lokale Modelle ermöglichen Offline-Nutzung ohne zusätzliches Abo; hohe Anpassbarkeit – Regeln, Agents und CI-Integration eignen sich für Engineering-Teams; freundlich für preisbewusste Einzelentwickler.

Grenzen: Die Erfahrung ist nicht so ausgereift wie bei kommerziellen Produkten, Konfigurations- und Lernaufwand sind höher; die Vervollständigungsqualität hängt stark vom gewählten Modell ab und schwankt bei den Standardeinstellungen; das Projekt wurde von Cursor übernommen – die unabhängige Weiterentwicklung ist beendet, die langfristige Wartungsrichtung ungewiss; lokale Modelle stellen Anforderungen an die Hardware, große Modelle ruckeln auf normalen Rechnern.

Für wen geeignet

  • Unternehmensentwickler mit strengen Anforderungen an die Privatsphäre von Codedaten;
  • Entwickler, die frei zwischen mehreren Modellen wechseln möchten;
  • Einzelnutzer, die mit lokalen Modellen einen KI-Programmierassistenten ohne laufende Kosten nutzen möchten;
  • Engineering-Teams, die ihren KI-Workflow tief anpassen wollen.

Häufige Fragen

Ist Continue komplett kostenlos? Die Open-Source-Version ist kostenlos, aber für Cloud-Modelle benötigen Sie einen eigenen API-Schlüssel und zahlen Modellgebühren; mit lokalen Modellen sind die Kosten praktisch null.

Wird Continue noch gepflegt? Das Projekt wurde von Cursor übernommen und veröffentlichte die finale Version 2.0.0; das Team ist zu Cursor gewechselt, die eigenständige Entwicklung ist abgeschlossen – Details in der offiziellen Ankündigung.

Welche Modelle kann ich anbinden? Fast alle OpenAI-kompatiblen Schnittstellen sowie gängige Modelle wie Anthropic und Google; lokal lassen sich Ollama und llama.cpp anbinden.

Eignet es sich für Einsteiger? Eher für Entwickler mit etwas Konfigurationserfahrung; wer sofort loslegen möchte, kann Copilot oder Cursor in Betracht ziehen.

Reichen lokale Modelle aus? Das hängt von Modellgröße und Hardware ab: Lokale Modelle der 7B-Klasse eignen sich für die tägliche Vervollständigung, komplexe Denkaufgaben sind besser mit Cloud-Modellen aufgehoben.
