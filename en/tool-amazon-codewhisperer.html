Overview

Amazon CodeWhisperer is an AI pair-programming assistant launched by Amazon Web Services (AWS). It first appeared in preview in June 2022 and became generally available in June 2023. When developers write a comment or type a little code, it automatically completes entire functions and logic, covering mainstream languages such as Python, Java, JavaScript, TypeScript, Go, and Rust, and provides code suggestions aligned with best practices for AWS services such as Lambda, S3, and EC2. On April 30, 2024, AWS merged CodeWhisperer into the Amazon Q Developer brand, and the original free tier and Pro subscription system continue to this day. For developers in the AWS ecosystem, it has long been the main free alternative to GitHub Copilot and a typical example of a "cloud vendor's self-developed coding assistant."

Core Features

First, code auto-completion. Developers only need to write a function name or a comment, and CodeWhisperer generates the complete function body based on context. IDE plugins cover VS Code, the full JetBrains family, Visual Studio, and AWS's own Cloud9; accepting a suggestion only requires pressing Tab.

Second, deep AWS service integration. It is specifically trained for AWS API calls — for example, when generating Lambda functions, S3 read/write, or IAM policy code, suggestions align with AWS official best practices. This is its most obvious difference from general-purpose coding assistants.

Third, security scanning. It can scan code for common vulnerability patterns, such as injection risks, hardcoded keys, and weak encryption algorithms, and provide specific fix suggestions. This capability is available in the free tier — a rare differentiator among similar tools.

Fourth, reference tracking and compliance hints. When generated code references open-source projects, it shows the corresponding license information, making it easy for teams to trace sources during compliance reviews.

Fifth, command-line scenarios. Since November 2023, AWS has offered CodeWhisperer for command line (now merged into Amazon Q Developer CLI), letting developers use natural language in the terminal to have AI write scripts and troubleshoot logs.

Getting Started

First-time use requires registering an AWS account; the free tier is fully open to individual developers with no payment method required. Installation is not complicated: search and install the plugin in the VS Code or JetBrains marketplace, sign in with AWS Builder ID or IAM Identity Center, and the plugin starts working in the editor.

The daily usage path is basically: write a comment or type a function signature, wait for the gray suggestion to appear, press Tab to accept or Esc to ignore. If suggestions are too distracting, you can turn off auto-suggestions in settings and trigger them manually with a shortcut. For AWS-related code, keep the security scan option enabled by default — it adds an extra check before you commit code.

One noteworthy change: after the 2024 rebranding, the old CodeWhisperer plugin automatically migrates to Amazon Q Developer; menus and settings entries carry the new brand, but the usage logic is basically the same. Overall, from installation to the first usable suggestion, it usually takes about ten to fifteen minutes.

Pros and Cons

Pros: the free tier is fully open to individual developers with zero startup cost; deep integration with AWS services delivers high-quality suggestions for cloud development; security scanning and license reference hints are clear plus points, practical for compliance-focused teams.

Cons: for teams that don't use AWS at all, its advantages are hard to see, and everyday completion quality still lags mature products like GitHub Copilot; after the rename to Q Developer, the product line has become more complex, and beginners can easily get confused between the free tier, Pro, and various quota descriptions; advanced command-line capabilities require some AWS experience to be useful.

Who It's For

  • Individual engineers and teams developing with AWS cloud services;
  • Beginners who want to try an AI coding assistant at zero cost;
  • Developers with code security scanning needs;
  • Developers already using the AWS IDE toolchain (Cloud9, etc.).

FAQ

Is CodeWhisperer still called that? It was renamed Amazon Q Developer in April 2024; old plugins migrate automatically and the features carry over.

Is the free tier enough? It basically covers everyday completion and security scans for individual developers; consider Pro when you need team management or higher quotas.

Which development environments are supported? VS Code, the JetBrains family, Visual Studio, and AWS Cloud9 all have plugin support.

Can it be installed alongside GitHub Copilot? Technically yes, but having both auto-suggestions enabled at the same time can interfere with each other, so it's better to keep only one.
