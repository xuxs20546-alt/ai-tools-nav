DeepSeek Tutorial: The Complete Guide to the Chinese Open-Source AI Breakthrough

2025-04-28 · 7 min read · 🐬

DeepSeek Is Not the "Domestic Alternative" You Imagine

When DeepSeek R1 launched in early 2025, the global AI community's reaction was telling: it wasn't "wow, China made a good model too," but rather "this model's reasoning process is actually visible." R1 was the first to transparently display a reasoning model's "thought process" (Chain of Thought) to users—before this, OpenAI's o1 series also performed deep reasoning, but the thinking process was hidden.

This seemingly minor design decision transformed how users interact with reasoning models. You can see how the model derives an answer step by step—including its intermediate hypotheses, calculation processes, moments of self-correction, and times it overturns its own assumptions. This is more educationally valuable than the final answer itself.

Three Access Points for Different Needs

Method 1: Web App (chat.deepseek.com) — Zero Barrier

Free, no special network setup required, register with phone or email. The interface is minimalist: an input box, a model selector (DeepSeek-V3 general-purpose model / DeepSeek-R1 reasoning model), no flashy features. Supports file uploads (images, PDF, Word, Excel, PPT, TXT), up to 100MB per file.

Important: model selection is not arbitrary. The two models serve completely different use cases.

  • Use V3 for: writing, translation, daily Q&A, creative brainstorming, simple code generation. V3 is fast with direct answers.
  • Use R1 for: mathematical proofs, complex logical reasoning, code debugging (especially multi-layered nested bugs), any task requiring rigorous argumentation. R1 self-reflects, checks for logical gaps, and may even overturn its own initial assumptions—but requires longer wait times (typically 10-60 seconds).

A practical rule of thumb: if your question can be answered directly in your head by a smart person (no pen and paper needed), use V3. If it requires "writing it out and reasoning step by step," use R1.

Method 2: API Access — The Most Affordable Mainstream Model Globally

DeepSeek's API pricing is its biggest competitive moat. V3's API pricing is roughly 1/15th of GPT-4o, and R1 is about 1/30th of GPT-4o (per million tokens). For large-scale use cases (chatbots, content generation pipelines, batch data analysis), this price difference means costs drop from "thousands of dollars a month" to "tens to hundreds of dollars a month."

Integration steps:

  1. Visit platform.deepseek.com, register and create an API Key
  2. The API is OpenAI-format compatible, meaning your existing ChatGPT API code doesn't need logic changes—just update base_url and api_key:
from openai import OpenAI
client = OpenAI(api_key="your-deepseek-key", base_url="https://api.deepseek.com")
response = client.chat.completions.create(
  model="deepseek-chat", # V3
  # model="deepseek-reasoner", # R1—note that reasoner output format differs
  messages=[{"role": "user", "content": "..."}]
)

Note on R1 API specifics: R1's API response contains two fields—reasoning_content (the thinking process) and content (the final answer). Most OpenAI-compatible client libraries won't automatically handle reasoning_content; you'll need to adapt manually. Additionally, R1 does not support system prompts, temperature, top_p, or most sampling parameters—these are hardcoded internally in R1.

Method 3: Local Deployment — The Only Choice for Privacy-Sensitive Scenarios

DeepSeek's entire model lineup is open-source. You can run locally with a single Ollama command:

ollama run deepseek-r1:7b # 7B distilled version
ollama run deepseek-r1:14b # 14B distilled version
ollama run deepseek-r1:70b # 70B distilled version, requires 48GB+ VRAM

Reality check: The 7B and 14B distilled versions perform decently for everyday conversation (blazing fast, runs on MacBook M-series), but there's a significant gap in complex reasoning compared to the full R1 (671B MoE). If your use case involves hard reasoning tasks like code debugging or mathematical proofs, rely on the API rather than local small models whenever possible. Small models have a clear ceiling on reasoning depth.

DeepSeek's Real Strengths (Not the Best at Everything)

An objective assessment after extensive real-world testing:

  • Mathematics and logical reasoning (R1): world-class, on par with OpenAI o1 and o3-mini. This is DeepSeek's true moat.
  • Programming (R1 + V3): R1 excels at debugging and complex algorithm implementation; V3 excels at quickly generating routine code. Using both together yields the best results.
  • Chinese writing (V3): The most natural Chinese-language feel and expressiveness among domestic models. Clearly outperforms GPT-4o and Claude on Chinese idioms, cultural references, and historical context.
  • English writing and creative content: falls short of Claude and GPT-4o. There's a gap in structural sense and linguistic richness.
  • Multimodal (image recognition, deep document understanding): not DeepSeek's strong suit. V3 can upload images for OCR, but visual comprehension and analysis capabilities are far behind GPT-4o and Claude 3.5.
  • Long document processing (over 50,000 words): the context window (V3 supports 1M tokens) is large enough, but accuracy of information extraction from the middle and later sections of long documents trails Kimi. When uploading very long documents, place critical information at the beginning and end.

DeepSeek vs ChatGPT: It's Not About Picking One—It's About Combining Them

Stop asking "Is DeepSeek better or ChatGPT?" The right question is: which tool for which task.

My personal usage strategy:

  • Daily writing, translation, quick Q&A → DeepSeek V3 (free + excellent Chinese)
  • Math problems, code debugging, tasks requiring rigorous logic → DeepSeek R1
  • English writing, creative content, visual understanding → Claude / GPT-4o
  • Long document analysis and cross-referencing → Kimi

This combination has nearly zero monthly cost (DeepSeek and Kimi both have free tiers). I only use paid services when I need high-quality English writing and visual comprehension.

Tip: R1's "Thought Process" Is the Best Learning Resource

If you're learning programming, mathematics, or any discipline requiring logical reasoning, R1's visible thought process may be the most underrated free educational resource on the internet. It doesn't just give you the answer—it shows you: how to approach a problem, how to verify intermediate results, how to backtrack and correct when contradictions arise, and which steps require repeated scrutiny.

Compare this thought process with your own reasoning, and you'll discover your own cognitive blind spots.
