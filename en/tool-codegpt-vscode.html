📖 Overview

CodeGPT is a VS Code extension positioned as a "neutral aggregation layer for AI coding" — it isn't tied to any single AI model provider, letting developers freely choose and switch between different AI models to assist with coding. With CodeGPT you can use OpenAI's GPT-4o, Anthropic's Claude, Google's Gemini, and various open-source models (deployed locally via Ollama/LM Studio) in VS Code, calling them on demand with your own API key.

CodeGPT offers code completion, a conversational coding assistant, code explanation, unit test generation, and code review. Its standout feature is "smart routing" — you can configure cheap GPT-4o-mini for everyday completion, Claude 3.5 Sonnet for complex architecture analysis, and Gemini 1.5 Pro for large codebase context analysis. This fine-grained orchestration lets developers keep code quality high while keeping API costs to a minimum. The basic version is free; Pro costs $9.99/month.

🔧 Core Features

CodeGPT's feature set is built around "multi-model integration and smart orchestration", carving out a unique position in the VS Code extension ecosystem:

Multi-model chat panel: Open the CodeGPT chat panel in the VS Code sidebar and talk directly to the selected AI model, just like using ChatGPT. Select a piece of code, right-click and choose "Ask CodeGPT", and it automatically answers with the current file as context. The panel supports multi-turn conversations; the context window depends on the selected model's limits (e.g., GPT-4o supports a 128K-token context).

Inline code completion: While you type in the editor, CodeGPT provides gray inline suggestions based on context; press Tab to accept. The completion engine can use different backend models — from fast GPT-4o-mini (about 200-400ms latency) to Claude Sonnet with stronger reasoning. Unlike GitHub Copilot, CodeGPT's completions don't send your code to third-party servers — everything goes through your own API key channel.

Code explanation & documentation: Select a function or class, type "explain this code" or "generate JSDoc comments", and CodeGPT analyzes the logic with the selected model and outputs structured Chinese/English explanations. This is especially useful for taking over legacy code, reading open-source projects, or preparing for code review.

Automatic unit test generation: Select a target function and CodeGPT analyzes its inputs, outputs, and edge cases to automatically generate matching unit tests (supporting mainstream frameworks like Jest, pytest, and JUnit). The generated tests cover normal paths and common error paths — developers just fine-tune and run.

Agent mode: Pro+ supports Agent workflows — give a natural-language description (e.g., "create a date formatting utility function under src/utils and write its tests"), and the CodeGPT Agent automatically plans steps, reads/writes files, and runs terminal commands to complete end-to-end development tasks in a sandbox.

🚀 Getting Started

The install process is minimal: search "CodeGPT" in the VS Code extension marketplace, install with one click, and restart the editor. On first launch, CodeGPT shows a welcome wizard that guides you through choosing a model provider and entering your API key — supporting OpenAI, Anthropic, Google AI, Azure OpenAI, Together AI, and local backends like Ollama/LM Studio, a dozen-plus backends in total. You can add or remove models anytime later in settings.

Once configured, a chat icon appears in the sidebar. Click it to open the panel; a model dropdown at the top lets you switch anytime. Select code, right-click and choose "CodeGPT: Explain Code", and the panel pops up with the selected code attached. During everyday coding, inline completion triggers automatically after you type 2-3 characters, showing gray hints below the cursor — press Tab to accept or Esc to dismiss.

For advanced users, enable "smart routing" rules in CodeGPT settings — for example, "completion→GPT-4o-mini", "refactoring→Claude 3.5 Sonnet", "large-file analysis→Gemini 1.5 Pro". That way you never need to switch models manually during daily work — the AI picks the model based on task type. At the start of each month, click the CodeGPT icon in the VS Code status bar to view token usage details per model.

👍 Pros & Limitations

Pros

  • Industry-leading model freedom: no vendor lock-in — supports nearly all mainstream AI models plus locally deployed open-source models (Ollama, LM Studio); developers fully control model choice.
  • Transparent, controllable costs: billed through your own API key; use cheap GPT-4o-mini (about $0.15 per million tokens) for everyday completion, switching to expensive models only for complex tasks — monthly API spending stays clearly trackable.
  • Privacy-friendly: code goes directly from your API key to the model provider; CodeGPT doesn't store or forward your code to its servers.
  • Smart routing reduces decision burden: configure task-to-model mapping rules once, and the system automatically picks the most cost-effective option day to day.

Limitations

  • Not a low setup barrier: you need to apply for and manage API keys for each provider — less friendly to non-technical users than GitHub Copilot's out-of-the-box experience.
  • Completion speed depends on the provider: with local models, speed depends on your hardware; with cloud models, it depends on network quality.
  • Less deep than native AI IDEs: Agent mode still trails native AI IDEs like Cursor Composer and Windsurf in capability and automation.

👥 Who It's For

  • Cost-sensitive development teams: cover everyday completion with a low-cost GPT-4o-mini API key, keeping per-person monthly AI spending under $5.
  • Enterprise compliance developers: finance and healthcare teams whose security policies require code to stay on the local network can use CodeGPT to connect locally deployed open-source models via Ollama.
  • Multi-model explorers: developers and tech leads who want to systematically compare how different models perform on specific coding tasks.
  • Open-source-stack users: independent developers and small teams who prefer open-source toolchains and want to avoid vendor lock-in.

❓ FAQ

Q: Is the CodeGPT free plan enough?
A: The free plan already includes the chat panel, code completion, and code explanation — you just need your own API key. It's fully adequate for light everyday use. The smart routing unlocked by Pro suits professional developers who code 4+ hours a day.

Q: Is CodeGPT's Agent mode safe?
A: Agent mode runs in a sandbox by default and cannot execute terminal commands without your confirmation. Pro+ users can customize Agent permission scope, but it's recommended to keep the "confirm before writing" option always on.

Q: What's the difference between CodeGPT and Continue?
A: Both are open-source multi-model VS Code extensions, but CodeGPT offers more polished smart routing, a visual configuration interface, and commercial support; Continue is more community-driven, more customizable, but more complex to configure.

Q: Can CodeGPT be used offline without a network?
A: Yes. Through CodeGPT's Ollama integration you can run open-source models like CodeLlama and Mistral on your local machine for fully offline AI-assisted coding.
