📖 Overview

Tongyi Qianwen is a large language model product launched by Alibaba Cloud, a subsidiary of Alibaba Group, in April 2023. The brand name is drawn from the Chinese phrase meaning "understanding all things and answering a million questions". Its underlying Qwen series of models is one of the most active domestically developed model families in the global open-source ecosystem — the Qwen2.5 series has surpassed 40 million cumulative downloads on Hugging Face, spawning more than 50,000 community fine-tuned variants. Unlike many peers, Tongyi Qianwen follows an "all-modality + all-size" approach: from lightweight on-device models with 0.5B parameters to flagship models with 72B parameters, and from text-only to fully multimodal versions that understand images, audio and video — letting users flexibly balance performance and cost for their actual scenarios.

The Qwen3 architecture upgrade in July 2025 is particularly noteworthy: the new models introduce a Mixture-of-Experts (MoE) architecture that cuts inference costs by 60% while maintaining flagship-level performance. Another key moat for Tongyi Qianwen is its deep integration with Alibaba Cloud infrastructure — enterprise users can complete the entire journey from model deployment to application launch directly on Alibaba Cloud's PAI platform, eliminating tedious cross-cloud configuration. Today, Tongyi Qianwen's AI capabilities are deeply embedded across Alibaba apps such as DingTalk, Amap and Taobao, covering high-frequency scenarios like office collaboration, navigation and e-commerce shopping.

Overview

Tongyi Qianwen (Qwen) is a series of large language model products launched by Alibaba Cloud under Alibaba Group, officially released as a brand in April 2023. Its underlying Qwen family of models is one of the most active domestic model lines in the global open-source LLM ecosystem — as of 2026, the Qwen series has surpassed 40 million cumulative downloads on Hugging Face and spawned more than 50,000 community fine-tuned variants covering dozens of vertical domains including translation, healthcare, law, code and education.

Tongyi Qianwen's core strategy is "all-modality + all-size" coverage. On the modality axis, the Qwen series includes text-only models, vision-language multimodal models (Qwen-VL), audio understanding models (Qwen-Audio) and video understanding models. On the size axis, options range from a lightweight 0.5B-parameter version that runs on phones to the 72B-parameter flagship, and since 2025 the Qwen3 series introduced the Mixture-of-Experts (MoE) architecture — users can pick the right model for their compute budget and accuracy requirements. Another key moat is deep integration with the Alibaba Cloud ecosystem: enterprise users can go from fine-tuning to production on the Alibaba Cloud PAI platform and connect seamlessly with Alibaba apps such as DingTalk, Amap and Taobao.

Core Features

Text generation & dialogue:Qwen models perform solidly on core Chinese-language capabilities such as text generation, dialogue, summarization, translation and code assistance. Qwen2.5-72B achieves results comparable to top international models on several Chinese benchmarks, and Qwen models show deep understanding of Chinese context and cultural background in semantic comprehension and logical reasoning.

Multimodal understanding (Qwen-VL series):Qwen-VL supports image captioning, visual question answering, document understanding, chart analysis and OCR. In e-commerce, Qwen-VL automatically analyzes product images and generates structured descriptions — a capability already in production use in Taobao's and Tmall's product management systems.

Code generation & assistance (Qwen-Coder series):the Qwen2.5-Coder series is specifically optimized for programming, supporting mainstream languages such as Python, Java, JavaScript and C++. It performs strongly on code benchmarks like HumanEval, handling everything from simple code completion to complex multi-file project generation.

Open-source ecosystem & community fine-tuning:the Qwen series is open-sourced under the Apache 2.0 license, so developers can freely download model weights, fine-tune and use them commercially. The community has built a rich set of downstream applications on Qwen — including Chinese legal-consultation models, medical-diagnosis models, classical-text translation models and financial-analysis models.

Getting Started

Tongyi Qianwen offers multiple ways to get started. For everyday users, the simplest route is to chat directly via the official website or the mobile app. The web interface is clean and supports text input, file upload (PDF, Word, images) and voice input. Conversations maintain multi-turn context memory and can handle long-text analysis at the ten-thousand-character level.

For developers, Alibaba Cloud provides the Bailian (ModelStudio) platform as a one-stop AI development tool. On Bailian, developers can call the Qwen API directly, upload datasets for fine-tuning, test model performance online, and integrate model capabilities into their own applications through the API gateway. The API is compatible with OpenAI's calling format, keeping migration costs low.

DingTalk users can @Tongyi Qianwen directly in work groups to use AI capabilities — generating meeting minutes, drafting announcements, querying knowledge bases — without leaving the workflow. This "embedded in existing work scenarios" approach makes AI usage far more frequent than standalone app models.

FAQ

Q: Can Qwen open-source models be used commercially?
A: The Qwen series is open-sourced under the Apache 2.0 license, permitting commercial use, modification and distribution. Note, however, that the training data of some Qwen models may include datasets with additional licensing restrictions — read the model's license and model card carefully before commercial use.

Q: How big is the gap between Tongyi Qianwen and ChatGPT?
A: In Chinese-language scenarios the gap is small — Qwen2.5-72B is on par with GPT-4 on several Chinese benchmarks. GPT-4 and Claude still hold an edge in English and multilingual capabilities. In open-source ecosystem activity and richness of Chinese downstream applications, Qwen surpasses most international models.

Q: What are the practical benefits of Qwen3's MoE architecture?
A: The core advantage of MoE (Mixture of Experts) is that inference activates only a portion of the model's parameters (rather than all of them), significantly reducing inference cost and latency. According to Alibaba Cloud's published data, Qwen3's inference cost is about 40% of comparable dense models while maintaining similar accuracy.

Q: Is data from the Tongyi Qianwen app and web version used for model training?
A: Per Tongyi Qianwen's privacy policy, users can choose whether conversation data may be used for model improvement. Data from enterprise plans and API calls is not used for model training by default. Enterprise users should carefully review the data privacy terms before use.
