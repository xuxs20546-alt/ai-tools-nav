Tool Overview

Continue is an open-source AI coding assistant that runs as a plugin for VS Code and JetBrains, letting developers use chat, code completion, and automated editing directly inside the editor. Its biggest selling point is “model freedom”: it is not tied to any single vendor, supporting cloud models from OpenAI, Anthropic, Google and others, as well as local models via Ollama and llama.cpp, and even in-house or self-hosted services. The project is released as open source with a public code repository, so developers can review, modify, and deploy it themselves, which makes it popular with teams that care about privacy and data control. At the same time, the open-source license and public repository have made it a common reference implementation for studying AI coding assistants. In 2025–2026, Continue was acquired by the AI code editor Cursor; the project shipped a final 2.0.0 release, removed telemetry, and the team joined Cursor to continue related work.

Core Features

First, in-editor chat. Select code in VS Code or JetBrains and ask questions: explain this code, point out potential problems, suggest refactoring — the AI's answers are based directly on the current project context.

Second, code completion. Suggestions appear automatically as you type, and different completion models can be configured. Local models work entirely offline, meeting the needs of offline or sensitive environments.

Third, automated editing and agent mode. Select code and describe the change you want in natural language (e.g., “rewrite this as an async implementation”), and the AI applies the changes directly in the editor; newer versions also support an Agent mode that automates multi-step development tasks.

Fourth, customization and programmability. Users can write their own prompt templates and custom commands, and even create shareable custom agents, baking the team's development conventions into the tool.

Fifth, CI integration. Continue 2.0 lets you bring AI review rules into the CI pipeline, so teams can run automated AI reviews before code is merged — “rules in your code, enforced in CI.”

Getting Started

Search for Continue in the VS Code extension marketplace and install it, or install it from the JetBrains plugin marketplace; after a restart, the Continue panel appears in the sidebar. On first use you need to configure a model: the simplest way is to enter an OpenAI-compatible API key; privacy-minded developers can install Ollama and pick a local model — you'll be up and running in minutes.

A typical workflow: open a project → select a piece of code → ask a question or have the AI explain it in the panel → use the Edit feature to let the AI change the code directly → review the diff and accept the changes. Once custom rules are configured, the AI's answers automatically follow team conventions such as code style and naming.

Because it is open source with many configuration options, Continue's learning curve is a bit steeper than out-of-the-box commercial assistants: configuring a model the first time and understanding the .continuerc config file takes some patience, but in return you get extreme flexibility. For the latest news after the acquisition, follow the official docs and repository announcements. In team scenarios, commit the config file and custom rules to the repository, and new members get consistent tool behavior as soon as they clone the project.

Pros and Cons

Pros: fully open source with transparent code, self-hostable, and strong data control; free choice of models — local models enable offline use with no extra subscription; deep customization — rules, agents, and CI integration suit engineering teams; friendly to budget-conscious individual developers.

Cons: the out-of-the-box experience is less polished than commercial products, with higher configuration and learning costs; completion quality depends heavily on the chosen model and varies a lot under default settings; the project has been acquired by Cursor, so its independent roadmap has ended and the long-term maintenance direction is uncertain; local models require decent hardware, and running large models on an ordinary computer can be sluggish.

Who It's For

  • Enterprise developers with strict requirements for code data privacy;
  • Developers who want to switch freely between multiple models;
  • Individual users who want a zero-cost AI coding assistant powered by local models;
  • Engineering teams willing to deeply customize their AI workflow.

FAQ

Is Continue completely free? The open-source version is free, but calling cloud models requires your own API key and model fees; with local models the cost is basically zero.

Is Continue still maintained? The project was acquired by Cursor and shipped a final 2.0.0 release; the team has joined Cursor and standalone development has concluded — see the official announcement for details.

Which models can I connect? Almost any OpenAI-compatible API, plus mainstream models such as Anthropic and Google; locally you can connect Ollama and llama.cpp.

Is it suitable for beginners? It suits developers with some configuration ability; if you want out-of-the-box, consider Copilot or Cursor.

Are local models good enough? It depends on model size and hardware: 7B-class local models handle everyday completion, while complex reasoning tasks are better paired with a large cloud model.
