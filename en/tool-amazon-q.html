Overview

Amazon Q is a family of generative AI assistants launched by Amazon Web Services (AWS). It debuted at AWS re:Invent in November 2023 and became generally available on April 30, 2024. It is not a single product but a set of AI capabilities for different scenarios: Amazon Q Business connects to internal company data to answer questions, Amazon Q Developer provides coding assistance for developers (formerly Amazon CodeWhisperer), and there are also versions for specific cloud services such as Q in QuickSight. For AWS customers, the value of Q lies in embedding generative AI capabilities directly into existing cloud workflows without having to build AI applications separately.

Core Features

First, enterprise knowledge Q&A. Q Business can connect to dozens of data sources such as S3, SharePoint, Salesforce, and Confluence, answering employee questions based on internal documents, databases, and systems while respecting existing permission systems — users can only see content they are authorized to access.

Second, developer coding assistance. Q Developer offers code completion and chat-based Q&A in IDEs, supports command-line operations and code review suggestions, and can help migrate legacy code such as Java 8 to newer versions. This "code transformation" capability sets it apart from general-purpose assistants.

Third, generative BI. Amazon Q integrated in QuickSight lets users generate charts, dashboards, and data summaries by asking questions in natural language, lowering the barrier for business users to perform data analysis.

Fourth, agentic capabilities for operations. Q Developer can act as an operations agent, helping troubleshoot issues in environments such as EC2 and EKS, providing remediation steps, and even executing some operations directly.

Fifth, enterprise-grade governance. Administrators can centrally manage user permissions, control data source scope, and audit AI usage records — critical for compliance in mid-to-large enterprises.

Getting Started

Before using Amazon Q Business, administrators need to create an application in the AWS console and configure data source connectors, which typically takes from a few minutes to tens of minutes depending on the number of data sources. Once configured, employees can ask questions through the web chat interface or integrated entry points such as Slack; answers cite the source documents for easy verification.

The developer path is simpler: install the Q Developer plugin in VS Code or JetBrains and sign in with your AWS account — the free tier is enough to start using code completion. Command-line users can install Q CLI and describe tasks in natural language in the terminal.

The key to the overall experience is permissions: all answers are constrained by IAM permissions, and when content cannot be found the system explicitly indicates "no permission to view," which is very different from personal chat tools. Teams starting out are advised to pilot with a single data source, confirm answer quality and citation accuracy, then gradually expand.

Pros and Limitations

Pros: deep integration with the AWS cloud ecosystem, rich data source connectors, a permission model consistent with the existing IAM system, and security and compliance in the first tier among enterprise AI assistants; on the developer side, coverage from code completion to code migration is comprehensive.

Limitations: the product line is complex — the separate pricing and feature boundaries of Business and Developer can confuse new users; appeal drops significantly for companies that do not use AWS infrastructure; answer quality depends heavily on the quality of data source documents, so poorly organized knowledge bases can hurt results; and optimization for Chinese-language material lags behind consumer-oriented general assistants.

Who It's For

  • Enterprise customers already deeply using AWS who want to deploy AI Q&A within the organization;
  • Development teams using AWS cloud services that need a coding assistant and code migration tools;
  • Mid-to-large enterprises with strict permission and compliance requirements;
  • Teams working on data analysis and BI that want to lower the barrier with natural language.

FAQ

What is the relationship between Amazon Q and CodeWhisperer? CodeWhisperer was renamed Amazon Q Developer in April 2024 and is the developer-focused part of the Q family.

Which data sources can Q Business connect to? It supports dozens of common enterprise systems such as S3, SharePoint, Confluence, Salesforce, and ServiceNow; see the official website for the full list.

Are Q's answers secure? Answers strictly follow the enterprise permission system — users can only access data they are authorized to see, and auditing is supported.

Can individuals use Amazon Q? Q Developer has a free tier you can try directly; Q Business targets enterprises and requires an administrator to enable it.
