About This Tool

Bolt.new is an AI full-stack development tool launched by StackBlitz in October 2024. Users describe what they need in natural language in the browser, and it generates a complete, runnable web application. Built on StackBlitz's proprietary WebContainers technology, it runs development environments such as Node.js directly in the browser, so AI-generated code can be instantly previewed, edited, executed, and even deployed — with no local installation required. After launch it quickly became a phenomenon, turning "building complete apps from prompts" from a demo into an everyday tool. The underlying WebContainers technology was originally used in StackBlitz's online development environment; combined with generative AI, it made "AI-generated runnable apps" accessible to everyone for the first time. From 2025 onward, the product is marketed uniformly under the Bolt brand, serving both developers and non-technical users.

Core Features

First, prompt-based app generation. Type a request like "build a to-do app with login functionality", and Bolt generates a complete project structure including frontend, backend, and database, running it directly in the in-browser preview window.

Second, conversational iteration. After generation, you can keep refining through conversation: adjust styles, add features, fix errors — the AI edits the code directly and refreshes the preview, with no need to open a code editor. The more specific your instructions, the more precise the changes; for example, "make the button rounded with a shadow" works far better than "make it look nicer".

Third, file and terminal access. You can view and modify project files in the interface and run commands such as npm in the integrated terminal, balancing "zero-friction generation" with "developer control".

Fourth, one-click deployment and sharing. Projects can be deployed to platforms like Netlify and Cloudflare, or a shareable link can be generated, making it easy to send a prototype to clients or colleagues for review.

Fifth, templates and integrations. You can start projects from StackBlitz templates, with GitHub integration, Figma design import, and more, so existing workflows can connect seamlessly.

Getting Started

Opening bolt.new, the homepage is a prompt input box. After signing in, just describe the app you want and see the first working version within seconds — this "works out of the box" experience is its most compelling feature.

The typical usage path: enter requirements → wait for generation → try it in the preview → request changes through conversation → deploy or export the code. For non-technical users, after the second step you can simply share the link to demo it; developers typically pull the generated project locally to continue developing.

One thing to note is usage consumption: Bolt charges by token. Complex conversations and large projects consume more credits; the free tier is limited, and heavy use basically requires a subscription. In addition, the quality of generated output depends on how clear your prompts are — describing requirements in detail (pages, interactions, tech stack) significantly improves output quality. Another practical tip: break requirements into several smaller conversations instead of cramming everything into one big prompt — first let the AI build the page skeleton, then add features and styles piece by piece. Generation quality tends to be more stable, and token consumption is easier to control.

Pros and Limitations

Pros: the entire workflow runs in the browser — zero installation, zero configuration, extremely low barrier to entry; a complete closed loop from generation to deployment, ideal for quickly validating ideas and building prototypes; conversational editing lets non-technical users participate in product iteration; generated code can be exported, so you're not locked into the platform.

Limitations: with token-based billing, costs are hard to estimate and complex projects burn through credits quickly; generated code has limited support for very large-scale or high-concurrency scenarios — production-grade systems still require manual refactoring; it demands a good network environment, and performance when running large projects in the browser depends on your device; direct access from mainland China can be unstable.

  • Independent developers who want AI to boost their full-stack development efficiency;

FAQ

What is the relationship between Bolt and Cursor? There is none. Bolt comes from StackBlitz and focuses on generating complete apps in the browser; Cursor is an independent AI code editor.

Is the free plan enough? It's fine for trying things out and lightweight prototypes; tokens are limited, so for real projects you'll basically need to upgrade to Pro.

Can the generated code be used commercially? Yes — you can export it and keep developing locally. For commercial use, we recommend combining it with your own code review and testing process.

Do I need to install Node.js? No. The runtime environment is provided by WebContainers in the browser.

Are Bolt-generated apps ready to go live directly? They're suitable for rapid launches of prototypes and small-to-medium apps, but production-grade systems should be deployed after code review, testing, and security assessment.
