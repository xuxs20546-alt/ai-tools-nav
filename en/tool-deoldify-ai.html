Tool Overview

DeOldify is an open-source deep learning project for restoring and colorizing old photos, started by developer Jason Antic in 2018. Its goal is to automatically colorize black-and-white photos and old footage while repairing damage. The project is hosted on GitHub (jantic/DeOldify) under the MIT open-source license, has an active community, and has spawned multiple online demo sites and mobile apps.

The NoGAN training method proposed by the project is widely discussed in the tech community: it combines the generation quality of GANs with the stability of pretrained transfer learning, keeping colors vivid while avoiding training collapse. It's also a key foundation of DeOldify's reputation.

Core Features

Photo colorization (Colorize). Feed in a black-and-white photo and get a natural color version. Two model styles are available: the Artistic model produces more vivid, expressive colors and suits portraits and artistic processing; the Stable model is more realistic and restrained, ideal for photos where realism matters.

Restore + colorize in one (Restore). Repairs physical damage such as scratches, creases, and stains while colorizing, so damaged old photos become "clean" at the same time as they become "colorful" — a practical step in digitizing old photos.

Video colorization (ColorizeVideo). Colorizes black-and-white footage frame by frame, suitable for documentary material and family history footage, though it demands noticeably more time and compute than single photos.

Free online trial. The official website offers a free Google Colab notebook — run the cells in order in your browser to colorize images without installing any software.

Local deployment and extensibility. The open-source code supports self-hosted services via FastAPI, Docker, and more, enabling batch photo processing or integration into your own restoration workflow.

Getting Started

The fastest way is to open deoldify.ai, enter the official Colab notebook, and run the cells in order: load the model → upload an image → run colorization → view and download the result. To fine-tune the output, switch between Artistic and Stable in the model selection cell and run it again.

Advanced users can clone the repository from GitHub and run the scripts on a local GPU to batch-process photos or videos; the official repository includes detailed model documentation and examples, and the community offers plenty of tutorials. For users unfamiliar with code, the Colab cells are pre-written, so following the steps is usually enough.

Pros & Limitations

Pros: fully open source and free with no quota anxiety; local offline processing keeps privacy-sensitive old photos off third-party servers; the Artistic/Stable models cover different aesthetic needs; a rich ecosystem of community tutorials and derivative tools.

Limitations: colorization is essentially the model's "reasonable guess" about colors — faces and complex scenes can occasionally look off; video colorization is slow; there's no official GUI, so everyday users need Colab or third-party wrapper apps, creating a learning curve.

FAQ

Q: Does DeOldify cost money? A: The official project is open source and free — use Colab's free quota to try it; local deployment only needs your own compute.

Q: What kind of computer do I need? A: For online use, just a browser; for local use, an NVIDIA GPU is recommended — CPU-only processing is very slow.

Q: Why are results occasionally unnatural? A: Colorization is the model's inference based on content features — the clearer the image and the more common the content, the more natural the colors usually are.

Q: Can it handle video? A: Yes — the official ColorizeVideo model is available, but it takes time; processing in segments is recommended.
