Обзор инструмента

Amazon CodeWhisperer — это ИИ-ассистент для парного программирования от Amazon Web Services (AWS). Впервые он появился в виде предварительной версии в июне 2022 года, а в июне 2023 года стал общедоступным. Когда разработчик пишет комментарий или вводит немного кода, ассистент автоматически дописывает целые функции и логику, поддерживая основные языки: Python, Java, JavaScript, TypeScript, Go, Rust и другие. Для сервисов AWS (Lambda, S3, EC2 и т. д.) он даёт рекомендации, приближенные к лучшим практикам. 30 апреля 2024 года AWS объединила CodeWhisperer с брендом Amazon Q Developer; прежний бесплатный тариф и подписка Pro действуют до сих пор. Для разработчиков в экосистеме AWS это давно основная бесплатная альтернатива GitHub Copilot и типичный пример «собственного ИИ-ассистента облачного вендора».

Основные функции

Первое — автодополнение кода. Достаточно написать имя функции или комментарий — CodeWhisperer сгенерирует полное тело функции на основе контекста. Плагины для IDE охватывают VS Code, всю линейку JetBrains, Visual Studio и собственный Cloud9 от AWS; принять подсказку можно нажатием Tab.

Второе — глубокая интеграция с сервисами AWS. Ассистент специально обучен на вызовах AWS API: при генерации функций Lambda, чтения/записи S3 или политик IAM подсказки соответствуют официальным лучшим практикам AWS. Это самое заметное отличие от универсальных ассистентов.

Третье — сканирование безопасности. Инструмент находит распространённые паттерны уязвимостей — риски инъекций, захардкоженные ключи, слабые алгоритмы шифрования — и даёт конкретные рекомендации по исправлению. Функция доступна уже в бесплатном тарифе, что редко встречается среди аналогичных инструментов.

Четвёртое — отслеживание ссылок и предупреждения о лицензиях. Когда сгенерированный код ссылается на open-source проекты, ассистент показывает информацию о соответствующей лицензии, что упрощает проверку происхождения кода при аудите соответствия.

Пятое — сценарии командной строки. С ноября 2023 года AWS предлагает CodeWhisperer for command line (теперь в составе Amazon Q Developer CLI): в терминале можно давать ИИ задания на естественном языке — написать скрипт, разобраться в логах и т. п.

Начало работы

Для первого использования нужна регистрация AWS-аккаунта; бесплатный тариф полностью открыт для индивидуальных разработчиков, привязка платёжного метода не требуется. Установка несложная: найдите плагин в маркетплейсе VS Code или JetBrains, установите и войдите через AWS Builder ID или IAM Identity Center — плагин сразу заработает в редакторе.

Повседневный сценарий прост: пишете комментарий или сигнатуру функции, ждёте серую подсказку, принимаете её клавишей Tab или игнорируете клавишей Esc. Если подсказки мешают, в настройках можно отключить автоматические предложения и вызывать их вручную горячей клавишей. Для кода, связанного с AWS, оставляйте включённым сканирование безопасности — это дополнительная проверка перед коммитом.

Важное изменение: после переименования в 2024 году старый плагин CodeWhisperer автоматически переходит в Amazon Q Developer — меню и настройки получают новый бренд, но логика использования практически не меняется. В целом от установки до первой полезной подсказки обычно проходит 10–15 минут.

Преимущества и недостатки

Преимущества: бесплатный тариф полностью открыт для индивидуальных разработчиков — нулевая стоимость старта; глубокая интеграция с сервисами AWS даёт качественные подсказки для облачной разработки; сканирование безопасности и уведомления о лицензиях — явные плюсы, полезные для команд, следящих за соответствием.

Недостатки: для команд, вообще не использующих AWS, преимущества почти не ощущаются, а качество повседневного дополнения всё ещё уступает зрелым продуктам вроде GitHub Copilot; после переименования в Q Developer линейка продуктов усложнилась, и новичкам легко запутаться между бесплатным тарифом, Pro и описаниями квот; продвинутые возможности командной строки требуют определённого опыта работы с AWS.

Кому подойдёт

  • Индивидуальные инженеры и команды, разрабатывающие с облачными сервисами AWS;
  • Новички, которые хотят бесплатно попробовать ИИ-ассистента для программирования;
  • Разработчики, которым нужно сканирование кода на уязвимости;
  • Разработчики, уже использующие инструментарий AWS IDE (Cloud9 и др.).

Частые вопросы

CodeWhisperer до сих пор так называется? С апреля 2024 года это Amazon Q Developer; старые плагины мигрируют автоматически, функции сохраняются.

Хватит ли бесплатного тарифа? Для повседневного дополнения и сканирования безопасности индивидуальным разработчикам — в основном да; Pro стоит рассмотреть при необходимости управления командой или больших квот.

Какие среды разработки поддерживаются? Плагины доступны для VS Code, продуктов JetBrains, Visual Studio и AWS Cloud9.

Можно ли установить вместе с GitHub Copilot? Технически да, но одновременные автоматические подсказки могут мешать друг другу — лучше оставить только один.
