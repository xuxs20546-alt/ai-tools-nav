О модели

GigaChat — это мультимодальная большая языковая модель, разработанная Сбером, крупнейшим банком России (Сбербанком). Она была впервые открыта для публики в 2023 году, в марте 2025 года вышло второе поколение GigaChat 2.0, а в апреле того же года доступ был открыт для всех пользователей. Позиционируясь как универсальный ИИ-ассистент с приоритетом русского языка, модель умеет отвечать на вопросы, писать тексты, генерировать код и изображения, а также предлагает API-сервисы для разработчиков. В серию GigaChat 2 входят флагманская GigaChat 2 MAX и сбалансированная GigaChat 2 Pro. По результатам российского бенчмарка MERA, GigaChat 2 MAX занимает лидирующие позиции в русскоязычных задачах и показывает результаты на уровне ведущих мировых моделей в двуязычном русско-английском тесте MMLU. Для русскоязычных пользователей и компаний, которым нужно обрабатывать документы на русском языке, это один из ключевых вариантов LLM в локальной экосистеме.

Основные функции

Общение и тексты.Веб-версия и приложение GigaChat предлагают повседневные диалоги, написание статей, черновики писем, перевод и шлифовку текста; официально модель описывается как способная «отвечать по-русски и понимать английский». Для русскоязычных пользователей она обычно превосходит прямой перевод с английских моделей в локальных выражениях и русских идиомах.

Генерация кода.Модель умеет генерировать и объяснять код на распространённых языках программирования, что делает её полезным помощником для разработчиков; через платформу разработчиков Сбера (developers.sber.ru) доступно и API-подключение.

Генерация изображений.GigaChat умеет создавать изображения по текстовому описанию, позволяя решать простые визуальные задачи прямо в чате; модели рисования Kandinsky из экосистемы Сбера используются вместе с ней.

Длинные тексты и сложные задачи.Согласно открытой документации API, GigaChat 2 MAX поддерживает контекстное окно до 128K токенов и подходит для профессиональных задач, таких как обработка длинных документов и глубокий анализ данных; GigaChat 2 Pro позиционируется как сбалансированная модель для быстрого выполнения повседневных задач.

API и корпоративные сервисы.Разработчики могут вызывать API GigaChat через платформу разработчиков Сбера и встраивать его в собственные приложения; в феврале 2026 года Сбер объявил о снижении корпоративных цен на API примерно на две трети, чтобы привлечь больше российских компаний.

Впечатления от использования

Для регистрации в GigaChat требуется российский номер телефона (через систему аккаунтов Сбера или сайт giga.chat) — это главный барьер для нерусскоязычных пользователей. После входа основное окно — это чистый чат со списком истории диалогов слева; поле ввода поддерживает загрузку текста и изображений.

При первом использовании можно сразу задавать вопросы в чате, например попросить модель резюмировать статью на русском или составить деловое письмо; модель отвечает за несколько секунд и поддерживает многоходовые уточнения. Чтобы сгенерировать изображение, достаточно описать сцену прямо в диалоге — модель выдаст результат с помощью функции рисования. Разработчикам, желающим подключить API, нужно зарегистрироваться на developers.sber.ru, создать приложение и получить ключ; оплата — по токенам, а в официальной документации есть примеры вызовов на Python и других языках.

В целом сценарий использования GigaChat похож на основные LLM-продукты, и для русскоязычных пользователей он почти не требует обучения. Для китайскоязычных же пользователей интерфейс не поддерживает китайский, а китайский язык не входит в ключевые возможности, поэтому модель подходит в первую очередь тем, у кого есть бизнес-потребности, связанные с русским языком.

Тарифы

GigaChat предлагает две системы — бесплатную и платную: для обычных диалогов есть бесплатный лимит, платная подписка GigaChat Max открывает более высокие лимиты и более мощные модели, а API тарифицируется по токенам с разными ставками для частных лиц и компаний. По данным официальной документации для разработчиков, с февраля 2026 года GigaChat-Max в личном API-тарифе стоит около 1950 рублей за 15 миллионов токенов; ставки часто меняются, поэтому ориентируйтесь на актуальные цены на официальном сайте.

Преимущества и ограничения

Преимущества.Русскоязычные навыки находятся в первой линии российских бенчмарков, локализация высокая; дружелюбный бесплатный лимит подходит для повседневного использования русскоязычными пользователями; диалог, тексты, код, изображения и API — полная экосистема; за моделью стоит Сбер, что гарантирует соответствие требованиям к данным и долгосрочную работу.

Ограничения.Высокий порог входа для нерусскоязычных — для регистрации нужен российский номер телефона; китайский язык не в приоритете, а у китайских пользователей много альтернатив; по глобальным многоязычным задачам модель всё ещё уступает топовым моделям, таким как OpenAI и Anthropic; корпоративные цены на API до снижения в начале 2026 года были сравнительно высокими.

Кому подойдёт

  • Специалистам в торговле между Китаем и Россией и трансграничном бизнесе, которым нужно обрабатывать русскоязычный контент, переводы или локализацию;
  • Техническим командам, разрабатывающим продукты для российского рынка или русскоязычные приложения;
  • Исследователям и контент-специалистам, изучающим экосистему русскоязычных LLM и сравнивающим модели;
  • Обычным пользователям в России с повседневными потребностями в ИИ.

Частые вопросы

Вопрос: GigaChat бесплатен?Ответ: У базовых диалогов есть бесплатный лимит; более продвинутые модели и API платные — уточняйте на официальном сайте.

Вопрос: Можно ли пользоваться без российского номера телефона?Ответ: Для регистрации обычно требуется российский номер, поэтому для зарубежных пользователей есть барьер.

Вопрос: Поддерживает ли GigaChat китайский язык?Ответ: Официально модель ориентирована на русский язык с пониманием английского; китайский не является приоритетной возможностью.

Вопрос: Как соотносятся GigaChat и GigaChat 2 MAX?Ответ: 2 MAX — флагманская модель второго поколения, выпущенная в марте 2025 года, значительно превосходящая первое поколение по возможностям.

Вопрос: Как разработчикам подключиться к GigaChat?Ответ: Зарегистрируйте приложение на developers.sber.ru и получите API-ключ; оплата по токенам.
