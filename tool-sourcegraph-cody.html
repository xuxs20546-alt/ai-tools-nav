工具简介

Sourcegraph 成立于 2013 年，以"代码搜索引擎"闻名，帮助开发者在海量代码库中快速定位函数、变量与调用关系。Cody 是 Sourcegraph 推出的 AI 编程助手，核心思路是"代码库感知"：与只看当前文件的补全工具不同，Cody 会把整个代码仓库作为上下文，理解项目结构、依赖关系与历史代码，再提供补全、问答与重构建议。它支持 VS Code、JetBrains 等主流 IDE，并允许用户选择不同的大模型后端。需要特别说明的是，根据 Sourcegraph 官方博客，2025 年 7 月 23 日起 Cody Free 与 Cody Pro 计划停止提供，产品重心转向企业级方案，个人开发者免费使用 Cody 的窗口已经关闭。

核心功能

  • 代码库感知的补全：补全建议基于整个仓库的上下文生成，跨文件、跨模块的符号引用也能被正确理解，比"局部补全"更贴合大型项目的实际情况。
  • Cody Chat 问答：用自然语言提问"这个函数在哪里被调用""这段逻辑为什么这样写"，Cody 会结合代码库给出带引用位置的答案，方便快速定位问题。
  • 多模型接入：官方文档显示 Cody 支持接入 Anthropic Claude、OpenAI 等主流大模型，企业可以根据成本、效果与合规要求选择模型（具体支持列表以官方文档为准）。
  • 代码搜索与导航：继承 Sourcegraph 的基因，把 AI 生成与精确代码搜索结合，回答问题时直接跳到真实代码位置。
  • 企业部署与合规：支持私有化部署，代码不出企业网络，满足金融、政企等行业的审计与合规要求（企业版能力）。

上手体验

在 VS Code 或 JetBrains 的插件市场安装 Cody 扩展，登录 Sourcegraph 账号并选择模型后即可开始使用。首次使用时，Cody 会要求指定代码库并建立上下文索引；之后在编辑器里写代码时会自动获得补全建议，也可以选中代码片段在 Chat 里提问"解释这段逻辑"或"帮我重构"。回答通常附带代码引用，点击即可跳转到对应文件。需要提醒的是，随着 Free 与 Pro 计划停用，当前个人开发者已无法直接注册使用 Cody，实际体验需要通过企业方案获取，具体接入流程以官网说明为准。

优点与局限

优点：对大型代码库的理解深度在同类工具中属于第一梯队，答案带可追溯的代码引用；支持多模型选择与企业私有化部署，合规能力强；与 Sourcegraph 代码搜索平台打通，适合"搜索+AI"一体化的工程组织。

局限：个人开发者免费路径已关闭，试用门槛明显提高；企业方案定价较高，面向团队而非个人用户；"代码库感知"需要索引与配置，初期学习成本高于普通补全插件。

适合人群

拥有大型代码库的研发团队；对代码安全与合规有硬性要求的金融机构与政企单位；需要代码搜索与 AI 助手一体化平台的企业；希望统一管理 AI 编程工具使用策略的工程组织。

同类工具对比

Cody 最直接的竞争对手是 GitHub Copilot 与 Cursor：Copilot 面向个人开发者、订阅门槛低；Cursor 是 AI 原生的独立编辑器；Cody 的优势则在企业级代码库理解与私有化部署。
