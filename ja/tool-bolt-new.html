ツール概要

Bolt.new は、StackBlitz が 2024年10月に発表した AI フルスタック開発ツールです。ユーザーがブラウザ上で自然言語で要件を一言述べると、実行可能な完全な Web アプリを生成します。StackBlitz 独自の WebContainers 技術を基盤に、Node.js などの開発環境をブラウザ内で直接実行するため、AI が生成したコードは即座にプレビュー・編集・実行でき、デプロイまで可能。ローカルに何もインストールする必要はありません。リリース後すぐに話題のプロダクトとなり、「プロンプトで完全なアプリを開発する」ことをデモから日常のツールへと変えました。もともと WebContainers 技術は StackBlitz のオンライン開発環境で使われていたもので、生成 AI と組み合わせることで、「AI が実行可能なアプリを生成する」ことを初めて誰でも使えるものにしました。2025年以降、製品は Bolt ブランドに統一され、開発者から非技術ユーザーまでを対象にサービスを提供しています。

コア機能

1つ目はプロンプトからのアプリ生成。「ログイン機能付きの ToDo アプリを作って」といった要件を入力すると、フロントエンド・バックエンド・データベースを含む完全なプロジェクト構成を生成し、ブラウザのプレビューウィンドウでそのまま実行します。

2つ目は対話型の反復開発。生成後もチャットで修正を続けられます。スタイルの調整、機能の追加、エラー修正など、AI がコードを直接編集してプレビューを更新。コードエディタを開く必要は一切ありません。指示が具体的なほど変更は正確になります。例えば「ボタンを角丸にして影を付けて」は「見た目を良くして」よりはるかに効果的です。

3つ目はファイルとターミナルへのアクセス。画面からプロジェクトファイルを閲覧・編集でき、統合ターミナルで npm コマンドなども実行可能。「ハードルゼロの生成」と「開発者による制御」の両立を実現しています。

4つ目はワンクリックデプロイと共有。プロジェクトは Netlify や Cloudflare などのプラットフォームにデプロイでき、共有リンクの生成も可能。プロトタイプを顧客や同僚にそのまま送って確認してもらえます。

5つ目はテンプレートと連携。StackBlitz のテンプレートからプロジェクトを開始でき、GitHub 連携や Figma デザインの取り込みなどにも対応し、既存のワークフローに組み込めます。

使い始める

bolt.new のトップページを開くと、そこはプロンプト入力ボックスです。ログイン後、作りたいアプリをそのまま説明すれば、数十秒で最初の実行版を確認できます。「箱から出してすぐ使える」この体験こそが最大の魅力です。

典型的な使い方の流れは、要件を入力 → 生成を待つ → プレビューで試す → チャットで修正を依頼 → デプロイまたはコードを書き出し、です。非技術ユーザーは2つ目のステップが終わればリンクを送ってデモできます。開発者は通常、生成したプロジェクトをローカルに落としてさらに開発を進めます。

注意したいのは使用量の消費です。Bolt はトークン単位で課金され、複雑な会話や大規模なプロジェクトはクレジットを多く消費します。無料枠は限られており、ヘビーに使うなら基本的にサブスクリプションが必要です。また、生成結果の品質はプロンプトの明確さに依存します。要件を具体的に（ページ、操作、技術スタック）書けば、出力品質は大幅に向上します。もう1つの実用的なコツは、要件を一度に大きなプロンプトへ詰め込むのではなく、複数の小さな会話に分けること。まず AI にページの骨格を作らせ、機能とスタイルを少しずつ追加していくと、生成品質は安定し、トークン消費も管理しやすくなります。

メリットと制限

メリット：ブラウザ内で全フローが完結し、インストールも設定も不要、参入障壁が極めて低い。生成からデプロイまで一気通貫で、アイデアの迅速な検証やプロトタイプ作成に最適。対話による修正で非技術ユーザーも製品開発に参加できる。生成したコードは書き出し可能で、プラットフォームに縛られない。

制限：トークン課金のためコストを見積もりにくく、複雑なプロジェクトは消費が速い。生成コードは超大規模・高並行のシナリオへの対応が限定的で、本番品質のシステムには人手による再構築が依然として必要。ネットワーク環境への要求が高く、ブラウザ内で大規模プロジェクトを動かす際のパフォーマンスは端末に左右される。中国本土からの直接アクセスは不安定。

よくある質問

Bolt と Cursor の関係は？ 関係ありません。Bolt は StackBlitz 製で、ブラウザ内で完全なアプリを生成するのが特徴。Cursor は独立した AI コードエディタです。

無料版で足りる？ 試用や軽いプロトタイプには十分です。トークンが限られているため、本格的なプロジェクトでは Pro へのアップグレードがほぼ必要です。

生成したコードは商用利用できる？ ローカルに書き出して開発を続けられます。商用利用では、自社のコードレビューとテストのプロセスと組み合わせることをおすすめします。

Node.js のインストールは必要？ 不要です。実行環境は WebContainers がブラウザ内で提供します。

Bolt が生成したアプリはそのまま本番公開できる？ プロトタイプや中規模アプリの迅速なリリースには向きますが、本番品質のシステムはコードレビュー・テスト・セキュリティ評価を経てからデプロイしてください。
