🧭 ツール概要

MiniMax（稀宇科技）は、上海に本社を置く AI 大規模言語モデル企業で、2021年末に設立。中国の「AI 大規模言語モデル六小竜」の一角とされています。自社開発のマルチモーダル大規模言語モデルを基盤に、世界市場向けにモデル API と一般消費者向け製品を提供しており、動画生成に強みを持つ Hailuo AI（海螺AI）が最も有名です。2026年1月9日、MiniMax は香港証券取引所メインボードに正式上場（銘柄コード 0100.HK）し、調達額は約48.2億香港ドル。当時、世界の AI 大規模言語モデル企業による IPO 規模の新記録となり、上場初日には株価が一時2倍以上に上昇しました。

MiniMax が解決する課題はシンプルです。一般ユーザーがテキストや画像から、映像が滑らかでカメラワークも自然なショート動画を生成できるようにすること。そして開発者が比較的低コストでアプリにマルチモーダル機能を組み込めるようにすることです。2024年9月、同社は大規模モデルの1日あたりのインタラクション数が30億回、1日あたり3兆トークンを処理していると発表。以来、同社の動画製品は世界の AI 動画ツールランキングの上位に常時ランクインしており、中国製 AI 動画分野を代表するプレーヤーのひとつです。

⚙️ コア機能

動画生成（Hailuo シリーズ）：Hailuo AI の中核機能は、テキストから動画、画像から動画への生成です。2025年6月18日、MiniMax は次世代の Hailuo 動画モデルを発表し、ネイティブ 1080p 動画制作に対応。Hailuo Video の Web 版・アプリ・オープンプラットフォーム API で同時に展開しました。ユーザーが中国語の説明文を入力すると、カメラワーク、被写体の動き、シーン変化を含む動画クリップが生成されます。

先頭・末尾フレームと指示制御：API 側では、Hailuo モデルは先頭・末尾フレーム技術に対応しています。ユーザーが開始画面と終了画面をそれぞれ指定すると、モデルが中間の動的なトランジションを自動補完。カットの開始と終了を正確に制御したい制作シーンに適しています。同社は、画像の内容を超えたテキスト指示も理解できると強調しており、「書いた通りに撮影できる」＝複雑な絵コンテの説明を分解して映像に反映できます。

マルチモーダル対話と制作：Hailuo AI アプリ内では、テキスト対話や画像生成にも対応。基盤は MiniMax 自社開発の abab / MiniMax-01 シリーズの大規模言語モデルで、中国語の理解・生成品質が大きな強みです。開発者はオープンプラットフォームから対話・音声・動画など複数のモデル API を呼び出すこともできます。

オープンソースとエコシステム：MiniMax は一部の大規模言語モデルをオープンソースで公開し、コミュニティによる自前デプロイや研究を可能にしています。また火山エンジン以外にも複数のクラウドプラットフォームや海外チャネルを通じてモデルを配布し、コンテンツクリエイター、マーケティングチーム、海外展開するアプリ開発者などを支援しています。

クリエイターコミュニティの公開フィードバックでは、Hailuo 動画のカメラワークの一貫性と被写体の一貫性が高く評価されています。長い中国語プロンプトも英訳せずそのまま入力できるため、中国国内のユーザーにとっては大きな利便性です。モデルはバージョン更新で継続的に進化しており、例えば2025年9月以降はオープンプラットフォーム API 経由で先頭・末尾フレーム生成が追加され、プロのクリエイターがカットの開始・終了画面を細かく制御できるようになりました。総合すると、MiniMax は「消費者向け製品＋オープンプラットフォーム」の二輪駆動戦略をとっており、一般ユーザーには使いやすい製品を、開発者には完全な導入チャネルを提供しています。

🖥️ 使い方

Hailuo AI を初めて使う場合、公式サイトにアクセスするか、電話番号で登録するとメイン画面に入れます。動画作成の入口は通常「Hailuo Video」セクションにあります。被写体、シーン、照明、カメラワークなどの説明を入力欄に書き、画面比率と長さを選んで「生成」をクリックするだけです。生成には数十秒から数分かかることが一般的で、完了後すぐにプレビューとダウンロードができます。

よく使う操作には他にも、以下のようなものがあります。「インスピレーション」やコミュニティセクションで他のユーザーの作品やプロンプトを閲覧し、ワンクリックで流用する。気に入らない結果はプロンプトを修正して再生成する。先頭・末尾フレーム機能で開始・終了画面を固定する。大量に生成したいユーザーは、オープンプラットフォームで API キーを作成し、公式ドキュメントに沿って動画生成 API を呼び出し、結果を自社の業務フローに組み込めます。注意点として、1080p やより長い動画などの仕様は通常、上位の会員プランや API 費用に対応しており、無料枠で試せるのは基本的な生成だけです。

チームユーザー向けには、オープンプラットフォームが利用量統計・残高管理・呼び出しログを提供し、コスト管理に役立ちます。個人ユーザーは「制作履歴」で過去の生成を管理し、気に入った作品を保存・アーカイブできます。AI 動画が初めてなら、まず無料版でシンプルな静的なシーン説明から始めてモデルの出力傾向に慣れ、その後カメラワークやトランジション、人物の動きなど複雑な指示に徐々に挑戦すると、プロンプトと完成映像の対応関係を把握しやすくなります。

💰 料金プラン

Hailuo AI の個人向けはサブスクリプション制です。無料版は毎日の基本枠を提供し、有料会員は複数プランに分かれており、解像度・長さ・生成回数の上限が異なります。2025年6月の会員料金改定後、最上位プラン「至臻版」の年会費は10,788元となり、価格が高すぎるという議論を巻き起こしましたが、同社は「すでに業界最安値」と回答。開発者向けは API の実利用量に応じた課金で、同社は動画生成 API の価格が業界低位にあると長期的に宣伝しています。

👍 長所と短所

長所：動画生成品質と中国語セマンティック理解は同種製品の中でも第一線級。対話・画像・動画までカバーする製品ラインの充実。開発者に優しい攻めた API 価格設定。上場企業であり、製品の長期的なメンテナンスが保証されています。

短所：最上位会員の年会費が約1万元に迫り、個人のヘビーユーザーには負担が大きい。生成結果にランダム性があり、複雑なシーンでは何度も「ガチャ」を引く必要がある。一部の高級仕様・機能は高額プランのみで、無料ユーザーが体験できる範囲は限定的です。

❓ よくある質問

Hailuo AI は無料ですか？ 無料版と毎日の利用枠があり、支払いなしで基本的な生成を試せます。より高品質な仕様には会員または API の支払いが必要です。

生成したコンテンツは商用利用できますか？ 商用ライセンスと著作権の帰属は公式サイトの利用規約をご確認ください。プランによって異なる場合があります。

動画生成 API の料金は？ トークンと生成仕様に応じて課金されます。同社は動画モデル価格として1,000トークンあたり0.015元程度を公表しており、詳細はオープンプラットフォームのリアルタイム見積もりをご確認ください。

一度にどのくらいの長さの動画を生成できますか？ 長さの仕様はモデルバージョンや会員プランによって異なります。製品内のオプションでご確認ください。

Hailuo AI にスマホアプリはありますか？ Web版とモバイルアプリを提供しており、制作履歴はマルチデバイスで同期。いつでもどこでも生成・閲覧できます。
