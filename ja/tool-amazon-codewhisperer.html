ツール概要

Amazon CodeWhisperer は、アマゾン ウェブ サービス（AWS）が提供するAIペアプログラミングアシスタントです。2022年6月にプレビューとして登場し、2023年6月に正式提供が開始されました。開発者がコメントを書いたり、少しコードを入力したりすると、関数やロジック全体を自動補完します。Python、Java、JavaScript、TypeScript、Go、Rustなど主要言語に対応し、Lambda、S3、EC2などのAWSサービスについてはベストプラクティスに沿ったコード提案を行います。2024年4月30日、AWSはCodeWhispererをAmazon Q Developerブランドに統合しましたが、従来の無料枠とProサブスクリプション体系は現在も継続しています。AWSエコシステムで開発する人にとって、GitHub Copilotに次ぐ主要な無料代替ツールであり、「クラウドベンダー自前のコーディングアシスタント」を理解する代表的な存在です。

主要機能

1つ目はコード自動補完です。関数名やコメントを書くだけで、コンテキストに基づいて関数全体を生成します。IDEプラグインはVS Code、JetBrainsファミリー全体、Visual Studio、AWSのCloud9に対応し、提案の受け入れはTabキーを押すだけです。

2つ目はAWSサービスとの深い統合です。AWS API呼び出しに特化して学習しており、Lambda関数やS3の読み書き、IAMポリシーなどのコード生成時にAWS公式のベストプラクティスに沿った提案を行います。これが汎用コーディングアシスタントとの最も明確な違いです。

3つ目はセキュリティスキャンです。インジェクションリスク、ハードコードされたキー、脆弱な暗号化アルゴリズムなど、一般的な脆弱性パターンをスキャンし、具体的な修正提案を提示します。この機能は無料枠でも利用でき、類似ツールでは珍しい差別化ポイントです。

4つ目は引用追跡とコンプライアンス通知です。生成コードがオープンソースプロジェクトを参照している場合、対応するライセンス情報を表示し、コンプライアンス審査時にチームが出所を追跡しやすくします。

5つ目はコマンドライン対応です。2023年11月からAWSはCodeWhisperer for command line（現在はAmazon Q Developer CLIに統合）を提供しており、ターミナルで自然言語を使ってスクリプト作成やログ調査などをAIに指示できます。

導入と使い方

初回利用にはAWSアカウントの登録が必要です。無料枠は個人開発者に完全に開放されており、支払い方法の登録は不要です。インストールも簡単で、VS CodeやJetBrainsのプラグインマーケットで検索してインストールし、AWS Builder IDまたはIAM Identity Centerでログインすればエディタで利用開始できます。

日常的な使い方は、コメントを書くか関数シグネチャを入力し、グレーの提案が表示されたらTabで受け入れ、Escで無視する、という流れです。提案が邪魔な場合は設定で自動提案をオフにし、ショートカットで手動トリガーに切り替えられます。AWS関連コードでは、デフォルトで有効なセキュリティスキャンを維持し、コミット前に追加のチェックを行うことをおすすめします。

注目すべき変更点として、2024年の改名後、旧CodeWhispererプラグインは自動的にAmazon Q Developerへ移行します。メニューや設定は新しいブランドになりますが、使い方はほぼ同じです。インストールから最初に使える提案が届くまで、通常は十数分で完了します。

メリットとデメリット

メリット：無料枠が個人開発者に完全に開放され、導入コストがゼロ。AWSサービスと深く連携し、クラウド開発での提案品質が高い。セキュリティスキャンとライセンス引用の通知は明確な加点要素で、コンプライアンス重視のチームに実用的です。

デメリット：AWSをまったく使わないチームには強みが活かせず、日常的な補完品質はGitHub Copilotなどの成熟製品にまだ及ばない。Q Developerへの改名後は製品ラインが複雑になり、初心者が無料枠・Pro・各種利用枠の説明で混乱しやすい。コマンドラインなどの高度な機能は、ある程度のAWS利用経験がなければ価値を発揮しにくい。

よくある質問

CodeWhispererは今もこの名前ですか？ 2024年4月からAmazon Q Developerに改名されました。旧プラグインは自動的に移行し、機能は継続されます。

無料枠で足りる？ 個人開発者の日常的な補完とセキュリティスキャンには基本的に十分です。チーム管理やより高い利用枠が必要になったらProを検討してください。

対応している開発環境は？ VS Code、JetBrainsシリーズ、Visual Studio、AWS Cloud9に対応したプラグインが提供されています。

GitHub Copilotと同時にインストールできますか？ 技術的には可能ですが、両方で自動提案を有効にすると互いに干渉しやすいため、片方だけにしておくことをおすすめします。
