ツール概要

GigaChat は、ロシア最大の銀行 Sber（ロシア連邦貯蓄銀行）が開発したマルチモーダル大規模言語モデルです。2023 年に初めて一般公開され、2025 年 3 月に第 2 世代の GigaChat 2.0 シリーズを発表、同年 4 月に全ユーザーへ開放されました。ロシア語優先の汎用 AI アシスタントとして、質問応答、テキスト作成、コード生成、画像生成に対応し、開発者向けの API サービスも提供しています。GigaChat 2 シリーズには、フラッグシップ版の GigaChat 2 MAX とバランス型の GigaChat 2 Pro があります。ロシア語ベンチマーク MERA の結果によると、GigaChat 2 MAX はロシア語タスクで上位にランクインし、ロシア語・英語のバイリンガルテスト MMLU でも世界の主要モデルと同等の成績を示しています。ロシア語ユーザーやロシア語の文書を扱う企業にとって、現地エコシステムで最も重要な大規模言語モデルの選択肢の一つです。

主な機能

会話と文章作成。GigaChat の Web 版とアプリ版は、日常会話、記事作成、メールの下書き、翻訳・推敲などの機能を提供し、公式には「ロシア語で回答でき、英語を理解できる」と説明されています。ロシア語話者にとって、ローカライズされた表現やロシア語の慣用表現では、英語モデルの直訳よりも優れていることが多いです。

コード生成。モデルは一般的なプログラミング言語のコード生成・解説に対応しており、開発者のプログラミング支援ツールとして利用できます。Sber の開発者プラットフォーム（developers.sber.ru）から API も提供されています。

画像生成。GigaChat はテキストの説明に基づいて画像を生成でき、チャット画面で簡単なビジュアル制作が可能です。Sber エコシステム内の Kandinsky シリーズの画像生成モデルとも連携して使われます。

長文と複雑なタスク。公開 API 資料によると、GigaChat 2 MAX は最大 128K token のコンテキストウィンドウをサポートし、長文書の処理や高度なデータ分析などの専門タスクに適しています。GigaChat 2 Pro は日常タスクを素早くこなすバランス型モデルとして位置づけられています。

API と企業向けサービス。開発者は Sber 開発者プラットフォーム経由で GigaChat API を呼び出し、自社アプリケーションに組み込めます。2026 年 2 月、Sber はより多くのロシア企業に利用してもらうため、企業向け API 価格を約 3 分の 2 引き下げると発表しました。

実際の使い勝手

GigaChat の登録にはロシアの電話番号が必要です（Sber アカウント経由または giga.chat 公式サイトから）。これが非ロシア語ユーザーにとって最大のハードルです。ログイン後のメイン画面はシンプルなチャットウィンドウで、左側に過去の会話履歴が並び、入力欄はテキストと画像のアップロードに対応しています。

初回利用時はそのままチャット欄で質問できます。例えばロシア語の記事の要約やビジネスメールの下書きを依頼すると、モデルは数秒で回答し、複数ターンの追加質問にも対応します。画像を生成したい場合は、チャットでそのまま画面のイメージを説明すれば、モデルが描画機能で結果を出力します。API を組み込みたい開発者は developers.sber.ru で登録し、アプリケーションを作成してキーを取得する必要があります。課金は token 単位で、公式ドキュメントには Python などによる呼び出し例が用意されています。

全体として、GigaChat の使い方は主流の大規模言語モデル製品とほぼ同じで、ロシア語ユーザーにとって学習コストはほぼゼロです。ただし中国語ユーザーにとっては、中国語のインターフェースがなく、中国語が主要な能力でもないため、ロシア語のビジネスニーズがある人に向いています。

料金プラン

GigaChat には無料と有料の 2 つの体系があります。通常の会話には無料枠があり、有料サブスクリプションの GigaChat Max でより高い利用量とより強力なモデルを利用できます。API は token 単位で課金され、個人と企業で料率が異なります。公式開発者ドキュメントを例に挙げると、2026 年 2 月以降、個人向け API プランの GigaChat-Max は約 1950 ルーブル/1500 万 token です。料率は頻繁に調整されるため、公式サイトのリアルタイム価格をご確認ください。

長所と短所

長所。ロシア語能力はロシア語ベンチマークで第一線クラスにあり、ローカライズ度が高い。無料枠が充実しており、ロシア語ユーザーの日常利用に適している。会話・文章作成・コード・画像・API など多様な形態を備え、エコシステムが完成されている。Sber を背景に持つため、データコンプライアンスと長期的な運営が保証されている。

短所。非ロシア語ユーザーにとってハードルが高い。登録にロシアの電話番号が必要。中国語は重点機能ではなく、中国語ユーザーには代替手段が多くある。世界的な多言語タスクでは OpenAI や Anthropic などのトップモデルに依然として差がある。企業向け API 価格は 2026 年初頭の引き下げ前は比較的高かった。

よくある質問

問：GigaChat は無料ですか？答：基本の会話には無料枠があります。より高度なモデルと API は有料です。詳細は公式サイトをご確認ください。

問：ロシアの電話番号がなくても使えますか？答：登録には通常ロシアの電話番号が必要で、海外ユーザーにとってはハードルがあります。

問：GigaChat は中国語に対応していますか？答：公式にはロシア語が中心で英語の理解に対応しています。中国語は重点的な能力ではありません。

問：GigaChat と GigaChat 2 MAX の関係は？答：2 MAX は 2025 年 3 月に発表された第 2 世代のフラッグシップモデルで、初代より大幅に能力が向上しています。

問：開発者はどうやって GigaChat に接続できますか？答：developers.sber.ru でアプリケーションを登録して API キーを取得し、token 単位で課金されます。
