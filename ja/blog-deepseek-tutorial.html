DeepSeek チュートリアル：中国発オープンソースAIの完全ガイド

2025-04-28 · 読了時間 7 分 · 🐬

DeepSeekは「国産代替品」ではない

2025年初頭にDeepSeek R1がリリースされた時、グローバルAIコミュニティの反応は示唆的でした。「中国も良いモデルを作った」ではなく、「このモデルの推論プロセスが実際に見える」という反応だったのです。R1は推論モデルの「思考プロセス」（Chain of Thought）をユーザーに透明に表示した初めてのモデルです。それ以前は、OpenAIのo1シリーズも深い推論を行っていましたが、思考プロセスは隠されていました。

この一見小さな設計上の決定が、ユーザーと推論モデルの関わり方を変えました。モデルがどのように段階を踏んで答えを導き出すのか ― 中間仮説、計算過程、自己修正の瞬間、自らの前提を覆す場面 ― を見ることができます。これは最終的な答えそのものよりも教育的価値が高いのです。

ニーズに応じた3つの利用方法

方法1：Web版（chat.deepseek.com）— ゼロハードル

無料、特別なネットワーク設定不要、電話番号またはメールで登録可能。インターフェースはミニマルで、入力欄とモデルセレクター（DeepSeek-V3汎用モデル / DeepSeek-R1推論モデル）のみ。ファイルアップロード（画像、PDF、Word、Excel、PPT、TXT）に対応し、1ファイル最大100MBまで。

重要：モデル選択は任意ではありません。2つのモデルは全く異なるユースケースに対応します。

  • V3を使う場面： 文章作成、翻訳、日常のQ&A、クリエイティブなブレインストーミング、簡単なコード生成。V3は高速で直接的な回答を返します。
  • R1を使う場面： 数学の証明、複雑な論理推論、コードデバッグ（特に多層的にネストしたバグ）、厳密な論証が必要なあらゆるタスク。R1は自己反省し、論理的な穴をチェックし、自らの初期仮説を覆すことさえあります ― しかし、より長い待ち時間（通常10〜60秒）が必要です。

実用的な判断基準：あなたの質問が、賢い人なら頭の中で直接答えられるもの（紙とペン不要）ならV3を使いましょう。もし「書き出して段階的に推論する」必要があるならR1を使いましょう。

方法2：API接続 — 世界で最も手頃な主力モデル

DeepSeekのAPI価格は最大の競争障壁です。V3のAPI価格はGPT-4oの約1/15、R1はGPT-4oの約1/30（100万トークンあたり）です。大規模利用のシナリオ（チャットボット、コンテンツ生成パイプライン、バッチデータ分析）では、この価格差はコストが「月に数千ドル」から「月に数十〜数百ドル」になることを意味します。

導入手順：

  1. platform.deepseek.com にアクセスし、登録してAPIキーを作成
  2. APIはOpenAI形式と互換性があり、既存のChatGPT APIコードはロジックの変更不要で、base_urlとapi_keyを変更するだけです：
from openai import OpenAI
client = OpenAI(api_key="your-deepseek-key", base_url="https://api.deepseek.com")
response = client.chat.completions.create(
  model="deepseek-chat", # V3
  # model="deepseek-reasoner", # R1 — 出力形式が異なることに注意
  messages=[{"role": "user", "content": "..."}]
)

R1 APIの特殊性に注意： R1のAPIレスポンスには2つのフィールド ― reasoning_content（思考プロセス）とcontent（最終回答）― が含まれます。ほとんどのOpenAI互換クライアントライブラリはreasoning_contentを自動処理しないため、手動で対応する必要があります。また、R1はシステムプロンプト、temperature、top_p、その他ほとんどのサンプリングパラメータをサポートしていません ― これらはR1内部に固定されています。

方法3：ローカルデプロイ — プライバシー重視のシナリオにおける唯一の選択肢

DeepSeekの全モデルラインナップはオープンソースです。Ollamaの1コマンドでローカル実行できます：

ollama run deepseek-r1:7b # 7B蒸留版
ollama run deepseek-r1:14b # 14B蒸留版
ollama run deepseek-r1:70b # 70B蒸留版、48GB以上のVRAMが必要

現実的な評価： 7Bおよび14Bの蒸留版は日常会話では十分な性能を発揮します（非常に高速で、MacBook Mシリーズで動作可能）。しかし複雑な推論では完全なR1（671B MoE）と大きな差があります。コードデバッグや数学の証明などハードな推論タスクがユースケースの場合、できるだけAPIを使用し、ローカルの小型モデルに依存しないでください。小型モデルには推論の深さに明確な上限があります。

DeepSeekの真の強み（すべてにおいて最強ではない）

広範な実践テストに基づく客観的な評価：

  • 数学と論理推論（R1）： 世界トップレベルで、OpenAI o1やo3-miniと同等。これがDeepSeekの真の堀です。
  • プログラミング（R1 + V3）： R1はデバッグと複雑なアルゴリズム実装に優れ、V3は定型コードの高速生成に優れています。両方を組み合わせると最高の結果が得られます。
  • 中国語の文章作成（V3）： 国産モデルの中で最も自然な中国語の語感と表現力。中国語の慣用句、文化的参照、歴史的文脈においてGPT-4oやClaudeを明確に上回ります。
  • 英語の文章作成とクリエイティブコンテンツ： ClaudeやGPT-4oに及びません。構造感覚と言語の豊かさに差があります。
  • マルチモーダル（画像認識、文書内容の深い理解）： DeepSeekの得意分野ではありません。V3はOCRのために画像をアップロードできますが、視覚的理解・分析能力はGPT-4oやClaude 3.5に大きく劣ります。
  • 長文書処理（5万字以上）： コンテキストウィンドウ（V3は1Mトークン対応）は十分に大きいですが、長文書の中盤から後半の情報抽出精度はKimiに劣ります。非常に長い文書をアップロードする際は、重要な情報を冒頭と末尾に配置してください。

DeepSeek vs ChatGPT：どちらか一方ではなく、組み合わせて使う

「DeepSeekとChatGPT、どちらが良いですか」と尋ねるのはもうやめましょう。正しい質問は：どのタスクにどのツールを使うかです。

私の個人的な使用戦略：

  • 日常的な文章作成、翻訳、素早いQ&A → DeepSeek V3（無料 + 優れた中国語）
  • 数学の問題、コードデバッグ、厳密な論理が必要なタスク → DeepSeek R1
  • 英語の文章作成、クリエイティブコンテンツ、視覚的理解 → Claude / GPT-4o
  • 長文書分析と相互参照 → Kimi

この組み合わせの月間コストはほぼゼロです（DeepSeekとKimiは両方とも無料枠あり）。高品質な英語の文章作成と視覚的理解が必要な場合のみ有料サービスを使用します。

ヒント：R1の「思考プロセス」は最高の学習リソース

プログラミング、数学、または論理的推論を必要とするあらゆる分野を学んでいるなら、R1の可視化された思考プロセスは、インターネット上で最も過小評価されている無料の教育リソースかもしれません。単に答えを与えるだけでなく、問題へのアプローチ方法、中間結果の検証方法、矛盾を発見した時の遡及修正方法、どのステップで繰り返し検討が必要かを示してくれます。

この思考プロセスを自分の推論プロセスと比較することで、自分の思考の盲点を発見できるでしょう。
