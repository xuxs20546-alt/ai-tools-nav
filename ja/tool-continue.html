ツール概要

Continue は、VS Code と JetBrains のプラグインとして動作するオープンソースの AI コーディングアシスタントで、開発者はエディタ内で直接チャット、コード補完、自動編集を利用できます。最大の特徴は「モデルの自由」です。特定のベンダーに縛られず、OpenAI、Anthropic、Google などのクラウドモデルに対応するほか、Ollama や llama.cpp 経由のローカルモデル、社内サービスや自前ホスティングのサービスにも接続できます。プロジェクトはオープンソースとして公開され、コードリポジトリも公開されているため、開発者は自らレビュー・改変・デプロイが可能で、プライバシーとデータ管理を重視するチームで人気があります。また、オープンソースライセンスと公開リポジトリにより、AI コーディングアシスタント研究の参考実装としても一般的です。2025〜2026年にかけて、Continue は AI コードエディタ Cursor に買収され、プロジェクトは最終版 2.0.0 をリリースしてテレメトリを削除し、チームは Cursor に加わって関連作業を継続しています。

主な機能

1つ目は、エディタ内チャットです。VS Code または JetBrains でコードを選択して質問できます。コードの説明、潜在的な問題の指摘、リファクタリングの提案など、AI の回答は現在のプロジェクトコンテキストに基づきます。

2つ目は、コード補完です。入力中に補完候補が自動表示され、補完モデルを設定で変更できます。ローカルモデルなら完全にオフラインで動作し、オフライン環境や機密環境のニーズに応えます。

3つ目は、自動編集とエージェントモードです。コードを選択して自然言語で変更内容を指示（例：「これを非同期実装に変えて」）すると、AI がエディタ内で直接変更を適用します。新しいバージョンでは、多段階の開発タスクを自動化するエージェント（Agent）モードにも対応しています。

4つ目は、カスタマイズとプログラミング性です。ユーザーは独自のプロンプトテンプレートやカスタムコマンドを作成でき、共有可能なカスタムエージェントも作成できます。チームの開発規約をツールに組み込めます。

5つ目は、CI 統合です。Continue 2.0 は AI レビュールールを CI パイプラインに組み込めるため、コードマージ前に自動で AI レビューを実行でき、「コード内のルールを CI で強制」できます。

はじめ方

VS Code の拡張機能マーケットプレイスで Continue を検索してインストールするか、JetBrains のプラグインマーケットプレイスからインストールします。再起動するとサイドバーに Continue パネルが表示されます。初回使用時はモデルを設定する必要があります。最も簡単なのは OpenAI 互換の API キーを入力することです。プライバシー重視の開発者は Ollama をインストールしてローカルモデルを選べば、数分で使い始められます。

典型的な使い方：プロジェクトを開く → コードを選択 → パネルで質問または AI に説明させる → 「編集」機能で AI にコードを直接修正させる → diff を確認して変更を受け入れる。カスタムルールを設定すると、AI の回答はコードスタイルや命名規約などのチーム規約に自動的に従います。

オープンソースで設定項目が多いため、Continue はすぐ使える商用アシスタントより学習曲線がやや急です。最初のモデル設定や .continuerc 設定ファイルの理解には少し耐忍が必要ですが、その代わりに非常に高い柔軟性が得られます。買収後の最新情報は公式ドキュメントとリポジトリのお知らせをご確認ください。チームでは設定ファイルとカスタムルールをリポジトリにコミットしておけば、新メンバーはクローン後すぐに一貫したツール動作を得られます。

長所と限界

長所：完全オープンソースでコードが透明、セルフホスト可能、データ管理性が高い；モデルを自由に組み合わせられ、ローカルモデルなら追加サブスクなしでオフライン利用可能；ルール・エージェント・ CI 統合などカスタマイズ性が高く、エンジニアリングチームに適す；予算重視の個人開発者にも友好的。

限界：すぐ使える商用製品ほどの体験ではなく、設定と学習コストが高い；補完品質は選択したモデルに大きく依存し、デフォルト設定では効果にばらつきがある；Cursor に買収され独立した開発ロードマップは終了しており、長期的なメンテナンス方針に不確実性がある；ローカルモデルはハードウェアに一定の要求があり、通常の PC で大規模モデルを動かすと動作が重くなる。

よくある質問

Continue は完全に無料ですか？ オープンソース版は無料ですが、クラウドモデルを利用するには自前の API キーとモデル費用が必要です。ローカルモデルならほぼゼロコストです。

Continue はまだメンテナンスされていますか？ プロジェクトは Cursor に買収され、最終版 2.0.0 をリリースしました。チームは Cursor に加わり、独立開発は一段落しています。詳細は公式のお知らせをご覧ください。

どのモデルを接続できますか？ OpenAI 互換のほぼすべての API と、Anthropic、Google などの主要モデルに対応。ローカルでは Ollama、llama.cpp を接続できます。

初心者に向いていますか？ ある程度設定できる開発者向けです。すぐ使いたい場合は Copilot や Cursor を検討してください。

ローカルモデルの性能で足りますか？ モデルサイズとハードウェアによります。7B クラスのローカルモデルは日常の補完で利用可能ですが、複雑な推論タスクはクラウドの大規模モデルと組み合わせるのがおすすめです。
