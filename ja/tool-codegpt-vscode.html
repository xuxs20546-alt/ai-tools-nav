📖 ツール概要

CodeGPT は VS Code 拡張機能で、「AI プログラミングにおける中立な集約レイヤー」として位置づけられています。特定の AI モデルプロバイダーに縛られず、開発者はコーディングを支援するさまざまな AI モデルを自由に選択・切り替えできます。CodeGPT を使えば、VS Code 内で OpenAI の GPT-4o、Anthropic の Claude、Google の Gemini、さらに各種オープンソースモデル（Ollama/LM Studio でローカル展開）を、自分の API キーで必要なときに呼び出せます。

CodeGPT は、コード補完、対話型プログラミングアシスタント、コード解説、単体テスト生成、コードレビューなどの機能を提供します。特筆すべきは「スマートルーティング」機能です。日常の補完には低コストの GPT-4o-mini、複雑なアーキテクチャ分析には Claude 3.5 Sonnet、大規模なコードコンテキスト分析には Gemini 1.5 Pro を設定できます。この細かな最適化により、コード品質を保ちながら API コストを最小限に抑えられます。ベーシック版は無料、Pro は月額 9.99 ドルです。

🔧 中核機能

CodeGPT の機能体系は「マルチモデル接続とスマートな最適化」を中心に構築され、VS Code 拡張機能エコシステムの中で独自のポジションを確立しています：

マルチモデルチャットパネル：VS Code のサイドバーで CodeGPT チャットパネルを開き、ChatGPT と同じように選択した AI モデルと直接対話できます。コードを選択して右クリックで「Ask CodeGPT」を選ぶと、現在のファイルコンテキストを添付して自動的に回答します。パネルはマルチターン対話に対応し、コンテキストウィンドウのサイズは選択したモデルの上限に依存します（例：GPT-4o は 128K トークンのコンテキストに対応）。

インラインコード補完：エディタでコードを入力すると、CodeGPT がコンテキストに基づいてグレーのインライン補完候補を表示し、Tab キーで受け入れます。補完エンジンには異なるバックエンドモデルを設定でき、高速な GPT-4o-mini（遅延約 200〜400ms）から推論能力の高い Claude Sonnet まで選択可能です。GitHub Copilot と違い、CodeGPT の補完はコードを第三者サーバーに送信せず、すべて自分の API キーチャネルで処理されます。

コード解説とドキュメント生成：関数やクラスを選択して「このコードを解説して」や「JSDoc コメントを生成して」と入力すると、CodeGPT が選択したモデルでロジックを分析し、構造化された中国語/英語の解説を出力します。レガシーコードの引き継ぎ、オープンソースプロジェクトのソースコード読解、コードレビューの準備に特に役立ちます。

単体テストの自動生成：対象の関数を選択すると、CodeGPT が入力・出力・境界条件を分析し、対応する単体テストを自動生成します（Jest、pytest、JUnit など主要なテストフレームワークに対応）。生成されたテストは正常系と一般的な異常系をカバーしており、開発者は微調整して実行するだけです。

エージェントモード：Pro+ 版はエージェントワークフローに対応しています。自然言語で指示を出すと（例：「src/utils の下に日付フォーマットのユーティリティ関数を作成し、対応するテストも書いて」）、CodeGPT エージェントが自動的に手順を計画し、ファイルの読み書きやターミナルコマンドの実行を行い、サンドボックス内でエンドツーエンドの開発タスクを完了します。

🚀 導入と使い方

インストールは非常に簡単です。VS Code の拡張機能マーケットプレイスで「CodeGPT」を検索し、ワンクリックでインストールしてエディタを再起動するだけです。初回起動時にはウェルカムウィザードが表示され、モデルプロバイダーの選択と API キーの入力が案内されます。OpenAI、Anthropic、Google AI、Azure OpenAI、Together AI、さらにローカルの Ollama/LM Studio など、10 種類以上のバックエンドに対応しています。後から設定画面でモデルをいつでも追加・削除できます。

設定完了後、サイドバーにチャットアイコンが表示されます。クリックしてパネルを開くと、上部のモデルドロップダウンからいつでも切り替え可能です。コードを選択して右クリックメニューの「CodeGPT: Explain Code」を選ぶと、選択したコードを添付してパネルが開きます。日常のコーディングでは、2〜3 文字入力するとインライン補完が自動的に発動し、カーソル下にグレーのヒントが表示されます。Tab で受け入れ、Esc で無視します。

上級者には、CodeGPT の設定で「スマートルーティング」ルールの有効化をおすすめします。例えば「補完タスク→GPT-4o-mini」「リファクタリングタスク→Claude 3.5 Sonnet」「大規模ファイル分析→Gemini 1.5 Pro」のように設定します。これで日常利用時に手動でモデルを切り替える必要はなく、AI がタスクの種類に応じて自動選択します。毎月初めに VS Code 下部のステータスバーで CodeGPT アイコンをクリックすると、モデルごとのトークン消費の明細を確認できます。

👍 メリットと限界

メリット

  • モデル選択の自由度は業界トップクラス：特定ベンダーに縛られず、主要な AI モデルとローカル展開のオープンソースモデル（Ollama、LM Studio）のほぼすべてに対応。開発者がモデル選択権を完全に掌握します。
  • コストの透明性と管理性：自分の API キーで課金され、日常の補完には安価な GPT-4o-mini（100 万トークンあたり約 0.15 ドル）、複雑なタスクにのみ高価なモデルを使用。月間 API 支出を明確に確認できます。
  • プライバシー重視：コードは自分の API キーからモデルプロバイダーへ直接送信され、CodeGPT はコードを保存・転送しません。
  • スマートルーティングで判断負荷を軽減：タスクとモデルの対応ルールを一度設定すれば、日常利用時に手動でモデルを切り替える必要がなく、システムが自動的にコストパフォーマンス最適なモデルを選択します。

限界

  • 設定の敷居が低くない：各モデルプロバイダーの API キーを自ら申請・管理する必要があり、非技術ユーザーには GitHub Copilot のようなすぐ使える体験ほどの親しみやすさはありません。
  • 補完速度はプロバイダーに依存：ローカルモデル使用時はローカルハードウェア、クラウドモデル使用時はネットワーク品質に依存します。
  • 機能深度はネイティブ AI IDE に及ばない：エージェントモードの能力と自動化度は、Cursor Composer や Windsurf などのネイティブ AI IDE と比べるとまだ差があります。

👥 おすすめのユーザー

  • コスト重視の開発チーム：低コストの GPT-4o-mini API キーで日常の補完をカバーし、月間の一人あたり AI 支出を 5 ドル以内に抑えられます。
  • 企業のセキュリティ・コンプライアンス担当開発者：コードをローカルネットワーク外に出せない金融・医療業界のチームは、CodeGPT 経由で Ollama にローカル展開したオープンソースモデルを接続できます。
  • マルチモデル探究者：特定のプログラミングタスクにおけるモデル性能を体系的に比較したい開発者や技術選定の責任者。
  • オープンソース技術スタックのユーザー：オープンソースのツールチェーンを好み、ベンダーロックインを避けたい独立開発者や小規模チーム。

❓ よくある質問

Q：CodeGPT の無料版で足りる？
A：無料版にはチャットパネル、コード補完、コード解説などの機能がすでに含まれており、自分の API キーを用意するだけです。日常的な軽い利用には十分です。Pro で解放されるスマートルーティングは、1 日 4 時間以上コーディングするプロフェッショナル開発者向けです。

Q：CodeGPT のエージェントモードは安全？
A：エージェントモードはデフォルトでサンドボックス環境で実行され、あなたの確認なしにターミナルコマンドを実行できません。Pro+ ユーザーはエージェントの権限範囲をカスタマイズできますが、「書き込み前の確認」オプションは常に有効にしておくことをおすすめします。

Q：CodeGPT と Continue の違いは？
A：両方ともオープンソースの VS Code マルチモデル拡張機能ですが、CodeGPT はより完成度の高いスマートルーティング、視覚的な設定画面、商用サポートを提供します。Continue はコミュニティ主導の色が強く、カスタマイズ性は高いものの設定はより複雑です。

Q：ネットワークのないローカル環境でも使える？
A：使えます。CodeGPT の Ollama 連携により、CodeLlama や Mistral などのオープンソースモデルをローカルマシンで実行し、完全オフラインの AI 支援プログラミングが可能です。
