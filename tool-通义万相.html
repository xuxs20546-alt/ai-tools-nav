工具简介

通义万相是阿里巴巴通义旗下的人工智能创意创作平台，旨在通过 AI 降低创作门槛，提供文生图、图生图、文生视频、图生视频、图像编辑等能力。它既可以作为普通用户使用的创作工具（网页与通义 App 内入口），也通过阿里云百炼平台向开发者提供 API 服务，是国内"免费额度 + 云计费"模式最具代表性的图像生成产品之一。

通义万相背后是阿里在视觉生成模型上的持续投入：2025 年 2 月阿里开源了 Wan 系列视频生成模型，同年 9 月发布开源图像生成基础模型 Qwen-Image。对中文用户而言，通义万相支持中文提示词，无需翻译或英文表达，加上阿里云生态的算力支持，是国产 AI 绘画工具中的主力选择。

核心功能

文生图。输入文字描述即可生成图片，官方文档显示其支持多种艺术风格与写实摄影效果。中文提示词直接可用，例如"雪山下的湖泊，晨雾，油画风格"，无需转换为英文。

图生图与风格迁移。上传参考图后，可以按目标风格重新生成，或对原图进行风格化改造，适合把照片转成插画、油画等效果，也适合基于设计稿做变体。

视频生成。万相系列支持文生视频与图生视频，公开资料显示其视频模型已迭代到较高版本，并曾开源供社区使用，普通用户可以直接在平台内生成动态素材。

图像编辑。提供对生成结果或上传图片的编辑能力，配合文生图、图生图形成完整的创作闭环，满足电商素材、设计稿迭代等需求。

API 与云服务。开发者可通过阿里云百炼调用万相模型，按量计费，新用户通常可获免费额度（公开资料显示新用户约有 50 张图片的免费生成额度），免费额度有效期约 30 至 90 天，到期后按量计费。

开源模型支持。万相背后的 Wan 系列视频模型与 Qwen-Image 图像模型均已开源，技术团队可以本地部署或二次开发，是国产视觉模型开源生态的重要组成部分。

上手体验

普通用户打开通义 App 或网页版，找到"万相"入口即可开始创作。文生图模式下，在输入框写下描述，选择画幅比例与风格，点击生成，几秒到几十秒内即可看到结果，不满意的可以微调提示词重新生成。想参考现实素材时，切到图生图上传照片，再描述期望的风格变化。

视频生成入口的流程类似，输入提示词或上传图片后选择时长即可。生成结果支持下载与分享，网页版还会提供历史记录管理。开发者的路径则是登录阿里云百炼，开通万相模型服务，领取新用户免费额度后按文档调用 API。整体体验顺畅，中文提示词的支持让国内用户可以"想到什么写什么"。

对设计师和运营人员，建议把万相当作"草图机"使用：先用文生图快速产出多个方向的初稿，选出方向后再用图生图细化，最后用图像编辑做局部调整，整套流程可以在几分钟内完成。开发者接入时，可以先在百炼控制台用可视化界面试跑几个提示词，确认效果和成本后再写代码，避免上线后才发现成本超预算。

价格方案

通义万相的定价分层清晰：面向普通用户的网页与 App 提供免费使用额度；面向开发者的 API 按量计费，新用户可领免费额度（公开资料显示约 50 张免费图片），百炼平台的新人免费额度有效期为 30 至 90 天；企业客户可以申请更高配额与定制服务。不同模型版本价格不同，请以阿里云百炼实时价格页为准。

优点与局限

优点。中文提示词原生支持，国内用户零门槛上手；文生图、图生图、视频生成、图像编辑能力齐全；阿里云生态加持，API 稳定、文档完善、免费额度友好；开源 Wan 与 Qwen-Image 模型为技术社区提供了参考。

局限。免费额度对重度创作用户不够用，长期使用需要按量付费；与 Midjourney 等顶尖产品相比，艺术风格的表现力在部分题材上仍有差距；网页版功能入口分散在通义体系内，新用户定位入口需要一点时间。

适合人群

  • 需要批量生成素材的电商与新媒体运营；
  • 想零成本体验 AI 绘画的入门用户；
  • 通过阿里云 API 集成图像能力的开发者；
  • 研究国产开源视觉模型的技术从业者。

通义万相的主要竞品是即梦 AI 与 Midjourney。即梦在视频生成与画布编辑上更强；Midjourney 以艺术质感见长；通义万相则在中文提示词、免费额度与开发者 API 生态上更有优势。

常见问题

问：通义万相免费吗？
网页与 App 提供免费使用额度，开发者 API 新用户也有免费额度（公开资料显示约 50 张图片），超出后按量计费。

问：Qwen-Image 和通义万相是什么关系？
Qwen-Image 是通义千问团队发布的开源图像生成基础模型（约 200 亿参数，Apache 2.0 许可），与万相平台能力同属阿里视觉生成体系。

问：可以生成视频吗？
可以。万相支持文生视频与图生视频，视频模型曾开源，平台内可直接使用。

问：开发者如何接入 API？
在阿里云百炼平台开通万相模型服务，领取免费额度后按官方文档调用即可，价格以实时价格页为准。
