工具简介

Janitor AI 是一个面向 C 端用户的 AI 角色扮演和互动对话平台。用户可以在平台上创建自定义的 AI 角色（包括角色外貌、性格、背景故事、说话风格等），然后与这些角色进行开放式的文字对话。平台的核心定位是"人类创意与 AI 魔法的交汇点"——它为创作者提供工具来构建沉浸式的虚拟世界和角色，也为喜欢互动的用户提供了一个探索 AI 叙事和角色扮演的空间。

Janitor AI 最初以"无审查的角色扮演平台"为差异化卖点吸引了大量从 Character.AI 迁移过来的用户。与 Character.AI 不同，Janitor AI 允许用户通过自带 API 密钥（如 OpenAI API）来驱动 AI 角色，也提供自研的 JanitorLLM 模型作为免费的内置选项。这种灵活的设计让用户可以选择使用高性能的商业模型或完全免费的内部模型。

核心功能

自定义角色创建：用户可以创建具有详细设定的 AI 角色，包括姓名、性别、性格标签、外貌描述、背景故事和对话风格。角色设定可以用自然语言描述（如"一位来自维多利亚时代的侦探，说话带古英语腔调，性格孤僻但正义感强"），系统会根据这些设定生成符合角色身份的对话。角色可以设为公开（其他用户也能与之对话）或私密（仅自己可见）。

多模型支持：Janitor AI 最具特色的功能之一是允许用户选择驱动 AI 角色的底层模型。用户可以使用 JanitorLLM（平台自研的免费模型），也可以通过 API 密钥接入 OpenAI 的 GPT 模型、Anthropic 的 Claude 或其他第三方模型。这种"BYO（自带模型）"方式让用户可以根据自己的需求和对内容自由的偏好选择最合适的模型。

公开角色社区：平台拥有一个活跃的公开角色社区，用户可以浏览、搜索和与数万个由其他创作者创建的角色互动。角色分类涵盖动漫、游戏、奇幻、浪漫、科幻等多个品类，社区活跃度较高。

自定义主题与界面：Janitor AI 支持用户通过自定义 CSS 来个性化聊天界面的外观，包括字体、配色、气泡样式等，满足用户的视觉定制需求。

上手体验

Janitor AI 的使用流程以浏览器端为主：访问 janitorai.com → 注册账号（支持邮箱注册）→ 浏览公开角色或创建自己的角色。创建角色的流程为：填写角色名称和头像 → 用自然语言撰写角色设定 → 选择驱动模型 → 开始对话。角色设定写得越详细（性格、说话方式、知识边界、禁止行为等），AI 的表现就越符合预期。

使用 JanitorLLM（免费内置模型）时，对话响应速度一般在数秒内完成，对话质量在同类社区驱动平台中处于中等水平。接入商业模型（如 GPT-4）时的对话质量会显著提升，但需要用户自行承担 API 调用费用。平台界面功能较为全面，但信息密度较高，新用户可能需要一些时间适应。

优点与局限

优点：一是免费使用 JanitorLLM 的门槛低，对于不想付费的用户来说是一个有吸引力的选择。二是多模型支持的灵活性——用户可以在免费模型和商业模型之间自由切换，按需选择性能或成本最优的方案。三是公开角色社区活跃，有大量现成的角色可以直接互动，降低了用户从零开始的门槛。四是角色设定自由度较高，支持自然语言描述和非标准角色设定。

局限：一是 JanitorLLM 的对话质量和稳定性有时波动，复杂语境下的上下文保持能力不如商业模型。二是平台的内容政策和管理较为松散，公开角色可能存在质量参差不齐的情况。三是缺少移动端原生 App，主要依赖浏览器访问。四是作为社区驱动的平台，服务稳定性偶尔受到用户流量波动的影响。

常见问题

问：Janitor AI 完全免费吗？
使用 JanitorLLM（平台自研模型）是免费的，但每日存在消息条数限制。如果通过 API 接入 OpenAI 等商业模型，则需按该服务的收费标准自行付费。

问：Janitor AI 和 Character.AI 哪个好？
取决于你的需求。如果你看重移动端 App 的便捷性、社区规模和对话稳定性，Character.AI 是更成熟的选择。如果你更重视内容自由度、模型切换的灵活性，或希望免费使用，Janitor AI 提供了有竞争力的替代方案。

问：我创建的角色会被其他人看到吗？
角色创建时可以选择公开或私密。公开角色会出现在社区目录中供其他用户互动，私密角色仅自己可见。你可以在角色设置中随时修改此选项。

问：JanitorLLM 和 GPT 模型的对话质量差距大吗？
有差距。在复杂剧情推进、多角色上下文跟踪和非英语对话场景下，GPT-4 等商业模型的表现明显优于 JanitorLLM。但对于日常的轻松对话和简单角色扮演场景，JanitorLLM 的表现足以满足多数用户需求。

问：怎么用我自己的 API 密钥接入 Janitor AI？
在 Janitor AI 的设置页面中，找到"API Settings"选项，选择对应的模型提供商（如 OpenAI），输入你的 API 密钥并保存即可。之后你在与角色对话时，AI 将使用你指定的模型而不是 JanitorLLM。请注意自行管理 API 密钥的安全。
