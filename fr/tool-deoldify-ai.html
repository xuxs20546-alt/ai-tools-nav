Présentation de l'outil

DeOldify est un projet open source de deep learning dédié à la restauration et à la colorisation de vieilles photos, lancé en 2018 par le développeur Jason Antic. Son objectif : coloriser automatiquement les photos noir et blanc et les anciennes vidéos tout en réparant les dommages. Le code est hébergé sur GitHub (jantic/DeOldify) sous licence MIT, la communauté est active, et plusieurs sites de démonstration et applications mobiles en sont dérivés.

La méthode d'entraînement NoGAN proposée par le projet est largement discutée dans le milieu technique : elle combine la qualité de génération des GAN avec la stabilité de l'apprentissage par transfert pré-entraîné, garantissant des couleurs éclatantes sans effondrement de l'entraînement. C'est aussi une base essentielle de la réputation de DeOldify.

Fonctionnalités principales

Colorisation automatique des photos (Colorize). Entrez une photo noir et blanc, obtenez une version colorée naturelle. Deux styles de modèles sont proposés : le modèle Artistic offre des couleurs plus vives et expressives, idéal pour les portraits et le traitement artistique ; le modèle Stable est plus réaliste et sobre, parfait pour les photos qui privilégient l'authenticité.

Restauration + colorisation combinées (Restore). Répare les dommages physiques (rayures, pliures, taches) tout en colorisant : les vieilles photos abîmées deviennent à la fois « en couleur » et « propres », une étape précieuse dans la numérisation des photos anciennes.

Colorisation vidéo (ColorizeVideo). Colorise les films noir et blanc image par image, adapté aux documentaires et aux archives familiales, mais nettement plus long et gourmand en calcul qu'une simple photo.

Essai gratuit en ligne. Le site officiel propose un notebook Google Colab gratuit : exécutez les cellules dans l'ordre dans votre navigateur pour coloriser vos images, sans installer le moindre logiciel.

Déploiement local et extensibilité. Le code open source prend en charge l'hébergement de services via FastAPI, Docker, etc., pour traiter des photos en masse ou intégrer vos propres flux de restauration.

Prise en main

Le plus rapide : ouvrez deoldify.ai, lancez le notebook Colab officiel et exécutez les cellules dans l'ordre : charger le modèle → téléverser l'image → lancer la colorisation → visualiser et télécharger le résultat. Pour ajuster le rendu, basculez entre Artistic et Stable dans la cellule de sélection du modèle, puis relancez.

Les utilisateurs avancés peuvent cloner le dépôt depuis GitHub et exécuter les scripts sur un GPU local pour traiter des photos ou vidéos en masse ; le dépôt officiel fournit une documentation détaillée et des exemples, et la communauté regorge de tutoriels. Pour ceux qui ne connaissent pas le code, les cellules Colab sont déjà préremplies : il suffit de suivre les étapes.

Avantages et limites

Avantages : entièrement open source et gratuit, sans inquiétude de quota ; traitement local hors ligne, les photos sensibles ne quittent pas votre machine ; les modèles Artistic/Stable couvrent différents besoins esthétiques ; tutoriels communautaires et outils dérivés très nombreux.

Limites : la colorisation reste une « estimation raisonnable » des couleurs par le modèle — visages et scènes complexes parfois inexacts ; colorisation vidéo longue ; aucune interface graphique officielle, les utilisateurs non techniques doivent passer par Colab ou des applications tierces, avec une courbe d'apprentissage réelle.

FAQ

Q : DeOldify est-il payant ? R : Le projet officiel est open source et gratuit — utilisez le quota gratuit de Colab pour l'essayer ; en local, il suffit de fournir la puissance de calcul.

Q : Quelle configuration est nécessaire ? R : En ligne, un simple navigateur suffit ; en local, un GPU NVIDIA est recommandé — le CPU seul est très lent.

Q : Pourquoi les résultats sont-ils parfois peu naturels ? R : La colorisation est une inférence du modèle à partir des caractéristiques du contenu : plus l'image est nette et le contenu courant, plus les couleurs sont généralement naturelles.

Q : Peut-il traiter des vidéos ? R : Oui — le modèle officiel ColorizeVideo existe, mais il est long ; un traitement par segments est conseillé.
