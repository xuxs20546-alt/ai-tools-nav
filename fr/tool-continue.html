Présentation de l'outil

Continue est un assistant de codage IA open source qui fonctionne comme plugin pour VS Code et JetBrains, permettant aux développeurs d'utiliser directement dans l'éditeur la conversation, la complétion de code et l'édition automatique. Son plus grand atout est la « liberté de modèle » : il n'est lié à aucun fournisseur unique, prend en charge les modèles cloud d'OpenAI, d'Anthropic, de Google, etc., et permet aussi de brancher des modèles locaux via Ollama et llama.cpp, ou même des services internes ou auto-hébergés. Le projet est publié en open source avec un dépôt public : les développeurs peuvent l'examiner, le modifier et le déployer eux-mêmes, ce qui le rend populaire auprès des équipes soucieuses de confidentialité et de maîtrise des données. La licence ouverte et le dépôt public en font aussi une implémentation de référence courante pour étudier les assistants de codage IA. En 2025–2026, Continue a été racheté par l'éditeur de code IA Cursor ; le projet a publié sa version finale 2.0.0, supprimé la télémétrie, et l'équipe a rejoint Cursor pour poursuivre les travaux.

Fonctionnalités clés

Premièrement, la conversation dans l'éditeur. Sélectionnez du code dans VS Code ou JetBrains et posez vos questions : expliquer ce code, repérer les problèmes potentiels, suggérer des refactorisations. Les réponses de l'IA s'appuient directement sur le contexte du projet.

Deuxièmement, la complétion de code. Des suggestions apparaissent automatiquement pendant la saisie, avec la possibilité de configurer différents modèles de complétion. Les modèles locaux fonctionnent entièrement hors ligne, ce qui répond aux besoins des environnements hors ligne ou sensibles.

Troisièmement, l'édition automatique et le mode agent. Sélectionnez du code et décrivez l'objectif en langage naturel (par exemple « transforme ceci en implémentation asynchrone ») ; l'IA applique les modifications directement dans l'éditeur. Les versions récentes prennent aussi en charge un mode Agent qui automatise les tâches de développement en plusieurs étapes.

Quatrièmement, la personnalisation et la programmabilité. Les utilisateurs peuvent écrire leurs propres modèles de prompts et des commandes personnalisées, et même créer des agents personnalisés partageables, afin d'intégrer les conventions de développement de l'équipe dans l'outil.

Cinquièmement, l'intégration CI. Continue 2.0 permet d'intégrer des règles de revue IA dans le pipeline CI, pour que les équipes exécutent automatiquement des revues IA avant la fusion du code : les règles du code sont appliquées dans la CI.

Prise en main

Recherchez Continue dans le marketplace d'extensions VS Code et installez-le, ou installez-le depuis le marketplace de plugins JetBrains ; après un redémarrage, le panneau Continue apparaît dans la barre latérale. Au premier lancement, il faut configurer un modèle : le plus simple est de saisir une clé API compatible OpenAI ; les développeurs soucieux de confidentialité peuvent installer Ollama et choisir un modèle local – tout fonctionne en quelques minutes.

Parcours typique : ouvrir un projet → sélectionner du code → poser une question ou demander une explication dans le panneau → utiliser la fonction Édition pour laisser l'IA modifier le code → vérifier le diff puis accepter. Une fois des règles personnalisées configurées, les réponses suivent automatiquement les conventions de l'équipe (style de code, conventions de nommage, etc.).

En raison de son caractère open source et de ses nombreuses options, Continue demande une courbe d'apprentissage un peu plus longue que les assistants commerciaux prêts à l'emploi : la première configuration du modèle et la compréhension du fichier .continuerc exigent un peu de patience, mais offrent en retour une flexibilité extrême. Pour les dernières actualités après le rachat, suivez la documentation officielle et les annonces du dépôt. En équipe, vous pouvez committer le fichier de configuration et les règles dans le dépôt : les nouveaux membres obtiennent un comportement cohérent dès le clonage.

Points forts et limites

Points forts : entièrement open source avec un code transparent, auto-hébergeable et un fort contrôle des données ; liberté totale de choix des modèles – les modèles locaux permettent une utilisation hors ligne sans abonnement supplémentaire ; grande personnalisation – règles, agents et intégration CI adaptés aux équipes d'ingénierie ; adapté aux développeurs individuels sensibles au budget.

Limites : l'expérience prête à l'emploi est moins aboutie que les produits commerciaux, avec des coûts de configuration et d'apprentissage plus élevés ; la qualité de complétion dépend fortement du modèle choisi et varie beaucoup avec la configuration par défaut ; le projet a été racheté par Cursor – la feuille de route indépendante est terminée et l'orientation de la maintenance à long terme reste incertaine ; les modèles locaux exigent un matériel correct, les gros modèles saccadent sur les machines ordinaires.

À qui s'adresse-t-il ?

  • Les développeurs d'entreprise ayant des exigences strictes en matière de confidentialité des données de code ;
  • Les développeurs qui veulent changer librement de modèle ;
  • Les utilisateurs individuels qui veulent un assistant de codage IA à coût quasi nul avec des modèles locaux ;
  • Les équipes d'ingénierie prêtes à personnaliser en profondeur leur flux de travail IA.

Questions fréquentes

Continue est-il entièrement gratuit ? La version open source est gratuite, mais l'appel aux modèles cloud nécessite votre propre clé API et le paiement des frais de modèle ; avec des modèles locaux, le coût est quasi nul.

Continue est-il toujours maintenu ? Le projet a été racheté par Cursor et a publié sa version finale 2.0.0 ; l'équipe a rejoint Cursor et le développement indépendant est terminé – voir l'annonce officielle.

Quels modèles puis-je connecter ? Presque toutes les interfaces compatibles OpenAI, ainsi que les modèles grand public comme Anthropic et Google ; en local, Ollama et llama.cpp.

Est-ce adapté aux débutants ? Plutôt aux développeurs ayant quelques compétences en configuration ; pour une utilisation immédiate, envisagez Copilot ou Cursor.

Les modèles locaux suffisent-ils ? Cela dépend de la taille du modèle et du matériel : les modèles locaux de la gamme 7B conviennent à la complétion quotidienne, tandis que les tâches de raisonnement complexes gagnent à utiliser un grand modèle cloud.
