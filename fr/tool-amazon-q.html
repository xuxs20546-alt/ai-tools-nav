Présentation de l'outil

Amazon Q est une famille d'assistants IA générative lancée par Amazon Web Services (AWS). Elle a été dévoilée en novembre 2023 lors de l'AWS re:Invent et est devenue généralement disponible le 30 avril 2024. Ce n'est pas un produit unique mais un ensemble de capacités IA destinées à différents scénarios : Amazon Q Business se connecte aux données internes de l'entreprise pour répondre aux questions, Amazon Q Developer offre une assistance à la programmation pour les développeurs (anciennement Amazon CodeWhisperer), et il existe aussi des versions dédiées à des services cloud spécifiques comme Q in QuickSight. Pour les clients AWS, l'intérêt de Q est d'intégrer directement l'IA générative dans les flux de travail cloud existants, sans avoir à développer des applications IA séparées.

Fonctionnalités clés

Premièrement, le Q&R sur les connaissances d'entreprise. Q Business peut se connecter à des dizaines de sources de données telles que S3, SharePoint, Salesforce et Confluence, répondant aux questions des employés à partir des documents, bases de données et systèmes internes, tout en respectant les systèmes d'autorisation existants : les utilisateurs ne voient que le contenu auquel ils ont droit d'accéder.

Deuxièmement, l'assistant de programmation pour développeurs. Q Developer propose l'auto-complétion de code et le Q&R par chat dans les IDE, prend en charge les opérations en ligne de commande et les suggestions de revue de code, et peut aider à migrer le code ancien comme Java 8 vers des versions plus récentes. Cette capacité de « transformation de code » le distingue des assistants généralistes.

Troisièmement, la BI générative. Amazon Q intégré à QuickSight permet de générer des graphiques, des tableaux de bord et des synthèses de données en posant des questions en langage naturel, ce qui abaisse la barrière de l'analyse de données pour les utilisateurs métier.

Quatrièmement, des capacités d'agent pour les opérations. Q Developer peut agir comme un agent d'exploitation, aider à diagnostiquer les incidents dans des environnements comme EC2 et EKS, fournir des étapes de remédiation et même exécuter directement certaines opérations.

Cinquièmement, la gouvernance au niveau entreprise. Les administrateurs peuvent gérer centralement les autorisations utilisateur, contrôler le périmètre des sources de données et auditer l'utilisation de l'IA – un point crucial pour la conformité dans les entreprises de taille moyenne et grande.

Prise en main

Avant d'utiliser Amazon Q Business, les administrateurs doivent créer une application dans la console AWS et configurer les connecteurs de sources de données, ce qui prend généralement de quelques minutes à quelques dizaines de minutes selon le nombre de sources. Une fois configuré, les employés peuvent poser des questions via l'interface de chat web ou des points d'entrée intégrés comme Slack ; les réponses citent les documents sources pour faciliter la vérification.

Le parcours côté développeur est plus simple : installez le plugin Q Developer dans VS Code ou JetBrains et connectez-vous avec votre compte AWS – le niveau gratuit suffit pour commencer l'auto-complétion de code. Les utilisateurs de la ligne de commande peuvent installer la Q CLI et décrire leurs tâches en langage naturel dans le terminal.

Le point clé de l'expérience globale, ce sont les autorisations : toutes les réponses sont soumises aux autorisations IAM, et lorsque le contenu est introuvable, le système indique explicitement « pas d'autorisation pour afficher », ce qui diffère nettement des outils de chat personnels. Les équipes qui démarrent devraient commencer par tester avec une seule source de données, vérifier la qualité des réponses et la précision des citations, puis étendre progressivement.

Points forts et limites

Points forts : intégration profonde avec l'écosystème cloud AWS, connecteurs de sources de données riches, modèle d'autorisation cohérent avec le système IAM existant, et sécurité/conformité dans le premier tiers des assistants IA d'entreprise ; côté développeur, la couverture de l'auto-complétion jusqu'à la migration de code est complète.

Limites : la gamme de produits est complexe – les tarifs et les périmètres fonctionnels distincts de Business et Developer peuvent dérouter les nouveaux utilisateurs ; l'attrait diminue fortement pour les entreprises qui n'utilisent pas l'infrastructure AWS ; la qualité des réponses dépend fortement de la qualité des documents sources, et une base de connaissances mal organisée dégrade les résultats ; enfin, l'optimisation pour les contenus en chinois est en retrait par rapport aux assistants généralistes grand public.

À qui s'adresse-t-il

  • Les entreprises clientes qui utilisent déjà intensivement AWS et souhaitent déployer un Q&R IA en interne ;
  • Les équipes de développement utilisant les services cloud AWS, qui ont besoin d'un assistant de programmation et d'outils de migration de code ;
  • Les entreprises de taille moyenne et grande soumises à des exigences strictes d'autorisation et de conformité ;
  • Les équipes d'analyse de données et de BI qui veulent abaisser la barrière grâce au langage naturel.

Questions fréquentes

Quelle est la relation entre Amazon Q et CodeWhisperer ? CodeWhisperer a été renommé Amazon Q Developer en avril 2024 ; c'est la partie de la famille Q destinée aux développeurs.

À quelles sources de données Q Business peut-il se connecter ? Il prend en charge des dizaines de systèmes d'entreprise courants comme S3, SharePoint, Confluence, Salesforce et ServiceNow ; la liste complète figure sur le site officiel.

Les réponses de Q sont-elles sûres ? Les réponses respectent strictement le système d'autorisations de l'entreprise – les utilisateurs n'accèdent qu'aux données pour lesquelles ils sont autorisés, et l'audit est pris en charge.

Les particuliers peuvent-ils utiliser Amazon Q ? Q Developer dispose d'un niveau gratuit pour tester directement ; Q Business cible les entreprises et nécessite l'activation par un administrateur.
