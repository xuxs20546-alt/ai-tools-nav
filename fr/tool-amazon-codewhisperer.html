Présentation

Amazon CodeWhisperer est un assistant de programmation en binôme propulsé par l'IA, lancé par Amazon Web Services (AWS). Présenté en avant-première en juin 2022, il est officiellement commercialisé depuis juin 2023. Lorsque le développeur écrit un commentaire ou saisit quelques lignes de code, il complète automatiquement des fonctions et des logiques entières, prenant en charge les langages courants comme Python, Java, JavaScript, TypeScript, Go et Rust, et fournit des suggestions de code alignées sur les bonnes pratiques pour les services AWS (Lambda, S3, EC2). Le 30 avril 2024, AWS a intégré CodeWhisperer à la marque Amazon Q Developer ; le niveau gratuit d'origine et l'abonnement Pro perdurent à ce jour. Pour les développeurs de l'écosystème AWS, il reste depuis longtemps la principale alternative gratuite à GitHub Copilot, et un exemple type d'« assistant de programmation développé en interne par un fournisseur de cloud ».

Fonctionnalités principales

Premièrement, l'auto-complétion de code. Il suffit d'écrire un nom de fonction ou un commentaire : CodeWhisperer génère alors le corps complet de la fonction selon le contexte. Les plugins IDE couvrent VS Code, toute la famille JetBrains, Visual Studio et le Cloud9 d'AWS ; une pression sur Tab suffit pour accepter une suggestion.

Deuxièmement, l'intégration approfondie des services AWS. L'outil est spécifiquement entraîné sur les appels d'API AWS — par exemple pour générer des fonctions Lambda, des lectures/écritures S3 ou du code de politique IAM, les suggestions suivent les bonnes pratiques officielles d'AWS. C'est la différence la plus nette avec les assistants génériques.

Troisièmement, l'analyse de sécurité. L'outil détecte les schémas de vulnérabilités courants — risques d'injection, clés codées en dur, algorithmes de chiffrement faibles — et propose des correctifs concrets. Cette capacité est disponible dès le niveau gratuit, un différenciateur rare parmi les outils similaires.

Quatrièmement, le suivi des références et les alertes de conformité. Lorsque le code généré s'appuie sur un projet open source, l'outil affiche les informations de licence correspondantes, ce qui facilite la traçabilité des sources lors des audits de conformité.

Cinquièmement, les scénarios en ligne de commande. Depuis novembre 2023, AWS propose CodeWhisperer for command line (désormais intégré à Amazon Q Developer CLI), ce qui permet d'utiliser le langage naturel dans le terminal pour faire écrire des scripts à l'IA ou diagnostiquer des journaux.

Prise en main

La première utilisation nécessite un compte AWS ; le niveau gratuit est entièrement ouvert aux développeurs individuels, sans carte de paiement. L'installation est simple : recherchez et installez le plugin sur le marketplace VS Code ou JetBrains, connectez-vous avec AWS Builder ID ou IAM Identity Center, et le plugin s'active dans l'éditeur.

L'usage quotidien tient en quelques gestes : écrire un commentaire ou saisir une signature de fonction, attendre la suggestion grise, appuyer sur Tab pour l'accepter ou sur Esc pour l'ignorer. Si les suggestions gênent, désactivez l'auto-suggestion dans les réglages et déclenchez-la manuellement via un raccourci. Pour le code lié à AWS, conservez l'analyse de sécurité activée : elle offre un contrôle supplémentaire avant le commit.

Un changement notable : après le changement de nom en 2024, l'ancien plugin CodeWhisperer migre automatiquement vers Amazon Q Developer ; les menus et réglages arborent la nouvelle marque, mais la logique d'utilisation reste identique. Dans l'ensemble, il faut généralement une dizaine de minutes entre l'installation et la première suggestion exploitable.

Avantages et limites

Avantages : le niveau gratuit est entièrement ouvert aux développeurs individuels, sans coût de démarrage ; l'intégration poussée avec les services AWS garantit des suggestions de qualité pour le développement cloud ; l'analyse de sécurité et les alertes de licence sont des atouts nets, très utiles pour les équipes soucieuses de conformité.

Limites : pour les équipes n'utilisant pas du tout AWS, les avantages sont difficiles à percevoir et la qualité de complétion quotidienne reste en retrait face à des produits matures comme GitHub Copilot ; depuis le changement de nom en Q Developer, la gamme s'est complexifiée et les débutants s'y perdent facilement entre niveau gratuit, Pro et les diverses explications de quotas ; les fonctions avancées en ligne de commande exigent une certaine expérience d'AWS.

Pour qui

  • Ingénieurs et équipes développant avec les services cloud AWS ;
  • Débutants souhaitant essayer gratuitement un assistant de programmation IA ;
  • Développeurs ayant besoin d'analyses de sécurité du code ;
  • Développeurs utilisant déjà la chaîne d'outils IDE d'AWS (Cloud9, etc.).

Questions fréquentes

CodeWhisperer porte-t-il encore ce nom ? Depuis avril 2024, il s'appelle Amazon Q Developer ; les anciens plugins migrent automatiquement et les fonctionnalités sont conservées.

Le niveau gratuit suffit-il ? Il couvre l'essentiel pour la complétion quotidienne et l'analyse de sécurité des développeurs individuels ; passez à Pro si vous avez besoin de gestion d'équipe ou de quotas plus élevés.

Quels environnements de développement sont pris en charge ? VS Code, la gamme JetBrains, Visual Studio et AWS Cloud9 disposent de plugins.

Peut-on l'installer en même temps que GitHub Copilot ? Techniquement oui, mais les suggestions automatiques simultanées risquent de se perturber ; mieux vaut n'en garder qu'un.
