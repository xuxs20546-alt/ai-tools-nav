Présentation de l'outil

GigaChat est un grand modèle de langage multimodal développé par Sber, la plus grande banque de Russie (Sberbank). Il a été ouvert au public pour la première fois en 2023, la deuxième génération GigaChat 2.0 est sortie en mars 2025, et l'accès a été ouvert à tous les utilisateurs en avril de la même année. Positionné comme un assistant IA généraliste prioritairement russophone, il peut répondre à des questions, rédiger des textes, générer du code et des images, et propose des services API aux développeurs. La série GigaChat 2 comprend le modèle phare GigaChat 2 MAX et le modèle équilibré GigaChat 2 Pro. Selon le benchmark russe MERA, GigaChat 2 MAX se classe en tête pour les tâches en russe et obtient des résultats comparables aux grands modèles mondiaux dans le test bilingue russe-anglais MMLU. Pour les russophones et les entreprises qui doivent traiter des documents en russe, c'est l'une des principales options LLM de l'écosystème local.

Fonctionnalités clés

Conversation et rédaction.Les versions web et application de GigaChat offrent la conversation courante, la rédaction d'articles, les brouillons d'e-mails, la traduction et le peaufinage ; la description officielle indique qu'il « répond en russe et comprend l'anglais ». Pour les russophones, il est généralement supérieur aux traductions directes des modèles anglais dans l'expression locale et les usages idiomatiques russes.

Génération de code.Le modèle peut générer et expliquer du code dans les langages de programmation courants, ce qui en fait un outil d'assistance utile pour les développeurs ; une API est également disponible via la plateforme développeurs de Sber (developers.sber.ru).

Génération d'images.GigaChat peut générer des images à partir de descriptions textuelles, ce qui permet de réaliser de simples créations visuelles dans l'interface de discussion ; les modèles de dessin Kandinsky de l'écosystème Sber fonctionnent en complément.

Textes longs et tâches complexes.Selon la documentation publique de l'API, GigaChat 2 MAX prend en charge une fenêtre de contexte allant jusqu'à 128K tokens, adaptée aux tâches professionnelles comme le traitement de longs documents et l'analyse approfondie de données ; GigaChat 2 Pro est positionné comme un modèle équilibré pour traiter rapidement les tâches courantes.

API et services aux entreprises.Les développeurs peuvent appeler l'API GigaChat via la plateforme développeurs de Sber et l'intégrer dans leurs propres applications ; en février 2026, Sber a annoncé une baisse d'environ deux tiers des prix de l'API entreprise afin d'attirer davantage d'entreprises russes.

Prise en main

L'inscription à GigaChat nécessite un numéro de téléphone russe (via le système de compte Sber ou le site giga.chat), ce qui constitue le principal obstacle pour les non-russophones. Après connexion, l'interface principale est une fenêtre de discussion épurée avec la liste des conversations passées à gauche ; le champ de saisie accepte les textes et les images.

Dès la première utilisation, on peut poser des questions directement dans la discussion, par exemple demander au modèle de résumer un article en russe ou de rédiger un e-mail professionnel ; le modèle répond en quelques secondes et prend en charge les relances sur plusieurs tours. Pour générer une image, il suffit de décrire la scène directement dans la conversation ; le modèle produit le résultat grâce à sa capacité de dessin. Les développeurs qui souhaitent intégrer l'API doivent s'inscrire sur developers.sber.ru, créer une application et obtenir une clé ; la facturation se fait au token, et la documentation officielle fournit des exemples d'appel en Python et dans d'autres langages.

Dans l'ensemble, le parcours d'utilisation de GigaChat ressemble à celui des grands modèles grand public, avec quasiment aucun apprentissage nécessaire pour les russophones ; pour les utilisateurs chinois en revanche, l'interface n'est pas en chinois et le chinois n'est pas une compétence principale – il convient surtout aux personnes ayant des besoins professionnels en russe.

Formules tarifaires

GigaChat propose deux systèmes : gratuit et payant. Les conversations ordinaires disposent d'un quota gratuit ; l'abonnement payant GigaChat Max débloque des usages plus élevés et des modèles plus puissants ; l'API est facturée au token, avec des tarifs différents pour les particuliers et les entreprises. Selon la documentation développeur officielle, depuis février 2026, le forfait API personnel GigaChat-Max coûte environ 1 950 roubles pour 15 millions de tokens ; les tarifs sont ajustés fréquemment, veuillez vous référer aux prix en temps réel sur le site officiel.

Forces et limites

Forces.Sa maîtrise du russe le place dans le premier groupe des benchmarks russophones, avec une forte localisation ; le quota gratuit est généreux et convient à un usage quotidien russophone ; conversation, rédaction, code, images et API : un écosystème complet ; adossé à Sber, il garantit la conformité des données et la pérennité de l'exploitation.

Limites.Le seuil d'entrée est élevé pour les non-russophones : l'inscription exige un numéro de téléphone russe ; le chinois n'est pas une priorité et les utilisateurs chinois ont de nombreuses alternatives ; sur les tâches multilingues mondiales, le modèle reste en retrait par rapport aux modèles de tête comme ceux d'OpenAI ou d'Anthropic ; l'API entreprise était relativement chère avant la baisse du début 2026.

Public cible

  • Les professionnels du commerce sino-russe et transfrontalier qui doivent traiter du contenu en russe, des traductions ou de la localisation ;
  • Les équipes techniques qui développent des produits pour le marché russe ou créent des applications en russe ;
  • Les chercheurs et créateurs de contenu qui souhaitent comprendre l'écosystème LLM russophone et comparer les modèles ;
  • Les utilisateurs russes ordinaires ayant des besoins quotidiens en IA.

Questions fréquentes

Q : GigaChat est-il gratuit ?R : Les conversations de base disposent d'un quota gratuit ; les modèles plus avancés et l'API sont payants – consultez le site officiel.

Q : Peut-on l'utiliser sans numéro de téléphone russe ?R : L'inscription exige généralement un numéro russe ; l'accès est donc difficile pour les utilisateurs à l'étranger.

Q : GigaChat prend-il en charge le chinois ?R : L'orientation officielle est le russe, avec compréhension de l'anglais ; le chinois n'est pas une compétence prioritaire.

Q : Quel est le lien entre GigaChat et GigaChat 2 MAX ?R : 2 MAX est le modèle phare de deuxième génération sorti en mars 2025, nettement plus performant que la première génération.

Q : Comment les développeurs intègrent-ils GigaChat ?R : Inscrivez une application sur developers.sber.ru pour obtenir une clé API ; facturation au token.
