Tutoriel DeepSeek : Le guide complet de la percée open-source chinoise en IA

2025-04-28 · 7 min de lecture · 🐬

DeepSeek n'est pas « l'alternative nationale » que vous imaginez

Lorsque DeepSeek R1 a été lancé début 2025, la réaction de la communauté mondiale de l'IA était révélatrice : ce n'était pas « wow, la Chine a aussi fait un bon modèle », mais plutôt « le processus de raisonnement de ce modèle est effectivement visible ». R1 a été le premier à afficher de manière transparente le « processus de réflexion » (Chain of Thought) d'un modèle de raisonnement aux utilisateurs – auparavant, la série o1 d'OpenAI effectuait également un raisonnement profond, mais le processus de réflexion était caché.

Cette décision de conception, apparemment mineure, a transformé la façon dont les utilisateurs interagissent avec les modèles de raisonnement. Vous pouvez voir comment le modèle dérive une réponse étape par étape – y compris ses hypothèses intermédiaires, ses processus de calcul, ses moments d'autocorrection et les fois où il renverse ses propres suppositions. Cela a plus de valeur éducative que la réponse finale elle-même.

Trois points d'accès pour différents besoins

Méthode 1 : Application web (chat.deepseek.com) — Aucune barrière

Gratuit, aucune configuration réseau spéciale requise, inscription par téléphone ou e-mail. L'interface est minimaliste : un champ de saisie, un sélecteur de modèle (DeepSeek-V3 modèle polyvalent / DeepSeek-R1 modèle de raisonnement), sans fonctionnalités superflues. Prend en charge le téléchargement de fichiers (images, PDF, Word, Excel, PPT, TXT), jusqu'à 100 Mo par fichier.

Important : le choix du modèle n'est pas arbitraire. Les deux modèles servent des cas d'usage complètement différents.

  • Utilisez V3 pour : la rédaction, la traduction, les questions-réponses quotidiennes, le brainstorming créatif, la génération de code simple. V3 est rapide avec des réponses directes.
  • Utilisez R1 pour : les preuves mathématiques, le raisonnement logique complexe, le débogage de code (en particulier les bugs imbriqués multi-niveaux), toute tâche nécessitant une argumentation rigoureuse. R1 s'auto-réfléchit, vérifie les lacunes logiques et peut même renverser ses propres hypothèses initiales – mais nécessite des temps d'attente plus longs (généralement 10 à 60 secondes).

Une règle empirique : si votre question peut être répondue directement dans la tête par une personne intelligente (sans papier ni crayon), utilisez V3. Si elle nécessite « de l'écrire et de raisonner étape par étape », utilisez R1.

Méthode 2 : Accès API — Le modèle établi le plus abordable au monde

La tarification API de DeepSeek est son plus grand avantage concurrentiel. Le prix de l'API V3 est environ 1/15e de GPT-4o, et R1 environ 1/30e de GPT-4o (par million de tokens). Pour les déploiements à grande échelle (chatbots, pipelines de génération de contenu, analyse de données par lots), cette différence de prix signifie que les coûts passent de « plusieurs milliers de dollars par mois » à « quelques dizaines à centaines de dollars par mois ».

Étapes d'intégration :

  1. Visitez platform.deepseek.com, inscrivez-vous et créez une clé API
  2. L'API est compatible avec le format OpenAI, ce qui signifie que votre code API ChatGPT existant n'a pas besoin de modifications logiques – il suffit de changer base_url et api_key :
from openai import OpenAI
client = OpenAI(api_key="your-deepseek-key", base_url="https://api.deepseek.com")
response = client.chat.completions.create(
  model="deepseek-chat", # V3
  # model="deepseek-reasoner", # R1 – notez que le format de sortie diffère
  messages=[{"role": "user", "content": "..."}]
)

Remarque sur les spécificités de l'API R1 : La réponse de l'API R1 contient deux champs – reasoning_content (le processus de réflexion) et content (la réponse finale). La plupart des bibliothèques clientes compatibles OpenAI ne traitent pas automatiquement reasoning_content ; vous devrez vous adapter manuellement. De plus, R1 ne prend pas en charge les prompts système, temperature, top_p ou la plupart des paramètres d'échantillonnage – ceux-ci sont intégrés en dur dans R1.

Méthode 3 : Déploiement local — Le seul choix pour les scénarios sensibles à la confidentialité

Toute la gamme de modèles DeepSeek est open source. Vous pouvez exécuter localement avec une seule commande Ollama :

ollama run deepseek-r1:7b # version distillée 7B
ollama run deepseek-r1:14b # version distillée 14B
ollama run deepseek-r1:70b # version distillée 70B, nécessite 48 Go+ de VRAM

Constat réaliste : Les versions distillées 7B et 14B fonctionnent correctement pour les conversations quotidiennes (très rapides, fonctionnent sur MacBook série M), mais il y a un écart significatif en raisonnement complexe par rapport au R1 complet (671B MoE). Si votre cas d'usage implique des tâches de raisonnement difficiles comme le débogage de code ou les preuves mathématiques, privilégiez l'API plutôt que les petits modèles locaux. Les petits modèles ont un plafond clair en profondeur de raisonnement.

Les véritables atouts de DeepSeek (Pas le meilleur en tout)

Une évaluation objective après des tests approfondis en conditions réelles :

  • Mathématiques et raisonnement logique (R1) : niveau mondial, comparable à OpenAI o1 et o3-mini. C'est le véritable fossé concurrentiel de DeepSeek.
  • Programmation (R1 + V3) : R1 excelle en débogage et implémentation d'algorithmes complexes ; V3 excelle en génération rapide de code routinier. L'utilisation conjointe des deux donne les meilleurs résultats.
  • Rédaction en chinois (V3) : La sensation linguistique et l'expressivité les plus naturelles parmi les modèles chinois. Surpasse nettement GPT-4o et Claude sur les expressions idiomatiques, les références culturelles et le contexte historique chinois.
  • Rédaction en anglais et contenu créatif : en deçà de Claude et GPT-4o. Il manque de sens structurel et de richesse linguistique.
  • Multimodal (reconnaissance d'images, compréhension approfondie de documents) : pas le point fort de DeepSeek. V3 peut télécharger des images pour l'OCR, mais les capacités de compréhension et d'analyse visuelles sont loin derrière GPT-4o et Claude 3.5.
  • Traitement de documents longs (plus de 50 000 mots) : la fenêtre de contexte (V3 prend en charge 1M tokens) est suffisamment grande, mais la précision d'extraction d'informations des sections médianes et finales des longs documents est inférieure à Kimi. Lors du téléchargement de très longs documents, placez les informations critiques au début et à la fin.

DeepSeek vs ChatGPT : Il ne s'agit pas d'en choisir un, mais de les combiner

Arrêtez de demander « DeepSeek est-il meilleur ou ChatGPT ? » La bonne question est : quel outil pour quelle tâche.

Ma stratégie d'utilisation personnelle :

  • Rédaction quotidienne, traduction, questions rapides → DeepSeek V3 (gratuit + excellent chinois)
  • Problèmes mathématiques, débogage de code, tâches exigeant une logique rigoureuse → DeepSeek R1
  • Rédaction en anglais, contenu créatif, compréhension visuelle → Claude / GPT-4o
  • Analyse de longs documents et recoupements → Kimi

Cette combinaison a un coût mensuel quasi nul (DeepSeek et Kimi ont tous deux des niveaux gratuits). Je n'utilise les services payants que pour la rédaction anglaise de haute qualité et la compréhension visuelle.

Astuce : Le « processus de réflexion » de R1 est la meilleure ressource d'apprentissage

Si vous apprenez la programmation, les mathématiques ou toute discipline nécessitant un raisonnement logique, le processus de réflexion visible de R1 est peut-être la ressource éducative gratuite la plus sous-estimée d'Internet. Il ne se contente pas de donner la réponse – il montre : comment aborder un problème, comment vérifier les résultats intermédiaires, comment revenir en arrière et corriger lorsque des contradictions apparaissent, et quelles étapes nécessitent un examen répété.

Comparez ce processus de réflexion avec votre propre raisonnement, et vous découvrirez vos propres angles morts cognitifs.
