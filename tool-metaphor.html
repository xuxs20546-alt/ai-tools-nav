工具简介

Metaphor 是 AI 搜索领域一家知名公司的原名，该公司成立于 2021 年，2023 年底更名为 Exa（exa.ai），因此"Metaphor"现在通常指代 Exa 的神经搜索引擎与搜索 API。与传统"关键词匹配"的搜索引擎不同，Exa 采用神经网络/向量嵌入方式理解查询语义，按"含义"而非关键词检索网页，专为 AI Agent 和 RAG（检索增强生成）应用设计。它提供 Search API、Deep Search 等接口，让开发者可以在一行代码内为 AI 应用接入实时网络数据，是 AI 编程生态中最常用的搜索 API 之一。

核心功能

语义/神经搜索。Exa 的核心是把查询和网页都映射到语义向量空间，检索"意思相近"的内容，而不是依赖关键词命中。对模糊描述、概念性查询（如"关于欧洲 AI 监管的深度文章"），它的结果往往比关键词搜索更贴切。

Search API。面向 AI Agent 的搜索接口：传入查询，返回网页链接、标题、摘要与结构化元数据；每次请求默认返回最多 10 条结果，适合作为 Agent 的工具调用。

Contents 内容接口。可以按 URL 或搜索 ID 批量获取网页正文，并对内容做 token 优化处理，让 AI 应用以更少的 token 消化网页信息，降低调用成本。

Deep Search（深度搜索）。面向复杂研究任务的增强模式，能执行多轮检索并组织结果，适合研究报告、竞品分析等需要深度信息收集的场景。

专为 Agent/RAG 设计。接口返回格式与 AI 工作流对齐，支持 Web 搜索工具调用（tool calls）、实时数据与结构化输出，官方定位即为"AI Agent 的搜索 API"。

上手体验

使用 Exa 需要先在官网注册账号，注册后账户会自动获得价值 20 美元的免费额度（约合两千多次搜索），此后免费档每月还会补充 10 美元额度——对个人开发者来说，日常开发测试基本够用。

拿到 API 密钥后，按官方文档用几行 Python 代码即可发起第一次搜索：传入 query 参数，返回结果中包含标题、URL、摘要等内容。Deep Search 模式的调用方式类似，但耗时更长、结果更深度。官方文档与示例代码完善，支持 Python、JavaScript 等主流语言，社区也有丰富的接入教程。

与普通搜索引擎的体验差异在于：Exa 没有面向消费者的"搜索框"，它更像一个供程序调用的数据管道。如果你只想日常查资料，它并不合适；如果你的 AI 应用需要"联网能力"，它则是最顺手的接口之一。

价格方案

Exa 采用按量付费（Pay-as-you-go）：免费档注册送 20 美元额度，每月再送 10 美元；Search 接口约 7 美元/千次请求，Deep Search 约 12 美元/千次请求，其余接口按各自基准价计费。用量大的团队可选择更高档位或联系商务，具体以官网实时价格为准。

优点与局限

优点。语义检索质量高，对模糊与概念性查询的适配明显优于关键词引擎；对 AI Agent/RAG 场景做了专门优化，接入成本低、返回格式友好；免费额度慷慨，个人开发者可以无压力评估；文档与 SDK 完善。

局限。没有面向普通消费者的产品形态，纯 API 定位限制了非技术用户；索引以英文网页为主，中文内容覆盖相对有限；按量计费模式下，高并发或大批量使用成本需要仔细规划；实时性与数据新鲜度依赖其索引更新策略。

适合人群

  • 开发 AI Agent、聊天机器人、RAG 应用的开发者与 AI 产品团队；
  • 需要为 LLM 应用接入实时网络数据的技术团队；
  • 做深度研究类产品（如 AI 研究助手）的创业者；
  • 关注 AI 搜索技术演进的研究者与工程师。

常见问题

问：Metaphor 和 Exa 是什么关系？答：Metaphor 是 Exa 的原名，2023 年底公司更名为 Exa，产品线延续至今。

问：Exa 有免费额度吗？答：有，注册送 20 美元额度，免费档每月再送 10 美元。

问：不会编程能用 Exa 吗？答：不能，Exa 是面向开发者的 API 服务，需要调用接口使用。

问：Exa 支持中文搜索吗？答：技术上可检索中文页面，但索引以英文为主，中文结果覆盖有限。

问：Deep Search 和 Search 有什么区别？答：Deep Search 面向复杂研究任务，会执行多轮检索且结果更深入，单价也更高，适合研究型场景。
