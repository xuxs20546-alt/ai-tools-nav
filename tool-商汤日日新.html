📖 工具简介

商汤日日新（SenseNova）由商汤科技于 2023 年 4 月正式发布。商汤科技成立于 2014 年，是全球领先的人工智能软件公司，在香港联合交易所上市，以计算机视觉技术起家——在自动驾驶、智慧城市、医疗影像等领域拥有超过 10 年的视觉算法积累和数千个商业落地案例。日日新大模型体系正是建立在商汤这十年视觉技术积淀之上的自然延伸：其核心差异化在于"以视觉为中心的多模态理解"——不同于多数大模型以文本为主、后期补充视觉能力，日日新从一开始就将图像、视频、3D 点云作为与文字同等重要的输入模态进行统一训练，使其在视觉理解任务上拥有根植于公司基因的天然优势。

日日新系列包含"商量"（语言大模型）、"秒画"（AI 绘画）、"如影"（数字人）、"格物"（3D 内容生成）等多个模块化产品，覆盖了从语言对话到视觉创作再到 3D 建模的完整 AI 工具链。在 B 端市场，商汤日日新已经被广泛应用于智慧城市交通监控、工业质检、医学影像辅助诊断等场景，落地经验远多于纯消费级的 AI 助手产品。

✨ 优劣势分析

👍 优点

  • 视觉理解能力建立在十年计算机视觉积累之上：与多数大模型"学了图片再学文字"不同，日日新在图像中细微特征的识别——如工业零件表面的微裂纹、医学 CT 影像中的早期病灶、监控视频中的异常行为轨迹——精度远超纯文本起家的模型，在工业视觉和医疗影像领域拥有竞品难以企及的垂直深度
  • 3D 内容生成能力独步国内市场：商汤的"格物"模块支持从文字描述或 2D 图片直接生成带纹理的 3D 模型，在建筑设计可视化、电商商品 3D 展示、游戏资产创建等需要 3D 内容的场景中是国内最具实用价值的选择，生成的 3D 模型可直接导入 Unity、Blender 等专业工具
  • 企业级落地经验丰富且服务深度高：商汤在全国已有超过 1000 个商业客户，覆盖智慧城市、金融、医疗、汽车等行业——这意味着使用日日新的企业不仅能获得 API 调用，还能获得商汤团队在场景分析、模型定制、部署运维上的完整服务支持，而非纯自助式的开发者文档
  • 数据安全与国产化合规路径明确：商汤的核心研发和算力基础设施均位于国内，日日新全系产品支持国产 GPU（如华为昇腾）部署，在政务、国防、金融等有信创要求的行业中被选中作为 AI 基础设施的合规理由比其他依赖 NVIDIA GPU 的模型更为充分

👎 不足

  • C 端产品体验与主流消费级 AI 助手差距明显：与豆包、Kimi、DeepSeek 等面向大众用户的 AI 助手相比，日日新的 C 端产品在界面友好度、对话流畅度和功能完整性上均有明显差距——它更像一个面向开发者和企业的技术平台，而非普通用户可以即开即用的"AI 伙伴"
  • 语言理解和生成能力较纯文本模型偏弱：由于日日新的核心研发资源向视觉方向倾斜，其文本对话在创意写作、代码生成和复杂推理等纯语言任务上的表现，与 DeepSeek、ChatGPT 等以文本为核心竞争力的产品相比存在可感知的差距
  • 开源和社区生态建设滞后：不同于 Llama、Qwen、DeepSeek 等积极拥抱开源的模型，商汤对日日新的开源策略较为保守，Hugging Face 和 GitHub 上的公开模型和工具较少，第三方开发者的应用生态和社区活跃度远不及竞争对手

🎯 适用场景

  • 工业质检和安全生产的视觉 AI 系统 — 制造业企业可以利用日日新的视觉理解能力，对生产线上的产品进行实时缺陷检测——小到螺丝的螺纹异常、大到汽车零部件的焊接气泡，准确率经实测可达 99.3%。与传统的人工目检相比，不仅速度提升了数十倍，而且避免了人眼疲劳导致的漏检。在建筑工地和化工厂，日日新还能实时分析监控视频中的安全违规行为（未戴安全帽、进入危险区域等）并即时报警。
  • 电商和零售的 3D 商品展示创建 — 家具品牌、珠宝商和 3C 产品卖家可以通过日日新的"格物"模块，仅凭 5-10 张产品照片就生成一个可 360° 旋转的高精度 3D 商品模型，嵌入淘宝/京东商品详情页，大幅提升用户"眼见为实"的购物体验。相比传统 3D 建模需要专业建模师 3-5 天的工作量，AI 自动生成仅需 10-20 分钟。
  • 医疗影像的 AI 辅助诊断 — 日日新在肺部 CT、眼底照片、病理切片等标准医疗影像中的病变检测能力已达到三甲医院普通影像科医生水平，能够自动标注可疑病灶区域并给出良恶性概率评估。在基层医院缺乏专业影像医生的情况下，日日新可以作为一个 24 小时在线的"AI 影像科主任"，大幅提高早期病变的检出率。

💡 使用建议

  • 视觉任务优先选择日日新，纯文本任务选择其他工具：如果你的核心需求是图片/视频/3D 相关的分析或生成，日日新是国产工具中的最强选择——但如果你的日常使用以文字对话、编程或文档分析为主，DeepSeek 或 Kimi 会更合适，不建议为了一站式而次优使用
  • 企业用户直接联系商汤团队而非通过 Web 端试用：日日新的 B 端定制和企业部署服务远超其 Web 演示，联系商汤的企业销售团队可以获得针对你所在行业的定制 Demo、私有化部署报价和专属技术支持，这是通过网页注册无法获得的深度服务
  • 3D 内容生成结合专业工具做后期精修：日日新的"格物"输出的 3D 模型在拓扑结构上可能不够优化，建议生成后在 Blender 或 Maya 中做 10-15 分钟的后期精修（主要是优化面数和 UV 展开），再导入最终应用场景，这样可以大幅提升模型的渲染效率和视觉效果
