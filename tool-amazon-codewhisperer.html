工具简介

Amazon CodeWhisperer 是亚马逊云科技（AWS）推出的 AI 结对编程助手，最初于 2022 年 6 月以预览形式亮相，2023 年 6 月正式商用。它能在开发者写下注释或输入少量代码时，自动补全整段函数与逻辑，覆盖 Python、Java、JavaScript、TypeScript、Go、Rust 等主流语言，并针对 AWS 服务（如 Lambda、S3、EC2）提供贴近最佳实践的代码建议。2024 年 4 月 30 日，AWS 将 CodeWhisperer 并入 Amazon Q Developer 品牌，原有免费层与 Pro 订阅体系延续至今。对身处 AWS 生态的开发者来说，它长期以来是 GitHub Copilot 之外最主要的免费替代品之一，也是了解"云厂商自研编程助手"的典型样本。

核心功能

第一是代码自动补全。开发者只需写出函数名或一段注释，CodeWhisperer 就会基于上下文生成完整的函数体，IDE 插件覆盖 VS Code、JetBrains 全家桶、Visual Studio 以及 AWS 自家的 Cloud9，接受建议只需按一下 Tab 键。

第二是 AWS 服务深度集成。它专门针对 AWS API 调用做了训练，例如生成 Lambda 函数、S3 读写、IAM 策略相关代码时，建议会贴合 AWS 官方最佳实践，这是它与通用编程助手最明显的差异点。

第三是安全扫描。它可以扫描代码中的常见漏洞模式，比如注入风险、硬编码密钥、弱加密算法等，并给出具体修复建议。这一能力在免费层中即可使用，是同类工具里较少见的差异化功能。

第四是引用追踪与合规提示。当生成的代码参考了开源项目时，它会提示对应许可证信息，方便团队在合规审查时追溯来源。

第五是命令行场景。2023 年 11 月起 AWS 推出了 CodeWhisperer for command line（现已并入 Amazon Q Developer CLI），开发者可以在终端里用自然语言让 AI 执行脚本编写、日志排查等任务。

上手体验

首次使用需要注册一个 AWS 账号，免费层对个人开发者完全开放，无需绑定支付方式。安装流程并不复杂：在 VS Code 或 JetBrains 的插件市场搜索安装后，通过 AWS Builder ID 或 IAM Identity Center 登录，插件即可在编辑器中生效。

日常使用路径基本是：写注释或敲下函数签名，等待灰色建议出现，用 Tab 接受、Esc 忽略。如果觉得建议太干扰，可以在设置中关闭自动建议，改为手动触发快捷键。对 AWS 相关代码，建议保留默认开启的安全扫描选项，它在提交代码前能多一道检查。

一个值得注意的变化是：2024 年更名后，旧版 CodeWhisperer 插件会自动迁移到 Amazon Q Developer，菜单和设置入口变成了新品牌，但使用逻辑基本一致。整体来说，从安装到第一次收到可用建议，通常在十几分钟内可以完成。

优点与局限

优点方面：免费层对个人开发者完全开放，起步成本为零；与 AWS 服务深度绑定，云上开发建议质量高；安全扫描与许可证引用提示是明显加分项，对注重合规的团队很实用。

局限方面：对于完全不使用 AWS 的团队，它的优势难以体现，日常补全质量相比 GitHub Copilot 等成熟产品仍有差距；更名 Q Developer 之后产品线变得复杂，初学者容易在免费层、Pro 和各类额度说明之间绕晕；命令行等进阶能力需要一定 AWS 使用经验才能发挥价值。

常见问题

CodeWhisperer 现在还叫这个名字吗？ 2024 年 4 月起已更名为 Amazon Q Developer，旧插件会自动迁移，功能延续。

免费层够用吗？ 对个人开发者的日常补全与安全扫描基本够用，需要团队管理或更高额度时再考虑 Pro。

支持哪些开发环境？ VS Code、JetBrains 系列、Visual Studio 以及 AWS Cloud9 均有插件支持。

能和 GitHub Copilot 同时安装吗？ 技术上可以，但两者同时开启自动建议容易互相干扰，建议只保留一个。
