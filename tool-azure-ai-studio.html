🪟 工具简介

Azure AI Studio 是微软推出的企业级生成式 AI 开发平台，于 2023 年微软 Build 大会首次亮相，之后逐步正式可用。它把 Azure OpenAI Service、模型目录、提示流（Prompt Flow）、评测工具与内容安全能力整合到一个工作台中，让开发团队在统一界面里完成模型选型、应用构建、测试评估与部署上线的全流程。2025 年微软 Ignite 大会后，相关能力整合进 Azure AI Foundry（Microsoft Foundry）品牌体系，官方文档与门户逐步统一迁移。

🔧 核心功能

模型目录（Model Catalog）：内置大量模型，既包括 OpenAI 的 GPT 系列，也涵盖 Llama、Mistral、Phi 等开源模型。可以在目录中直接预览、试用并部署。

提示流（Prompt Flow）：可视化编排工具，用拖拽方式把提示词、工具调用、数据处理串联成完整工作流，方便构建 RAG（检索增强生成）应用与多步骤 AI Agent。

内置评测：提供自动评测与人工评测面板，可对回答质量、相关性、安全性等维度打分，上线前完成质量把关。

内容安全（Azure AI Content Safety）：内置违规内容检测服务，识别并过滤有害文本与图像，满足企业合规要求。

部署与运维：支持按量付费的 Serverless 部署、托管计算与流式输出，与 Azure AI Search、Functions、Monitor 等生态深度集成。

🧭 上手体验

登录 Azure 门户创建 AI Studio 资源（需要 Azure 账号），进入工作室后先开通 Azure OpenAI 服务并部署一个 GPT 模型，即可在 Playground 中对话测试。进阶用户用 Prompt Flow 把"检索文档→拼提示词→调用模型→返回答案"串成可运行流程，再通过评测面板迭代质量。整体上手门槛高于普通消费级 AI 工具，适合有开发基础的团队。

❓ 常见问题

Azure AI Studio 免费吗？平台工作台本身可免费使用，但调用模型与计算资源按量计费。

可以用 GPT-4 吗？可以，Azure OpenAI Service 提供 GPT 系列模型，需开通相应资源。

和 ChatGPT 有什么区别？ChatGPT 是面向普通用户的产品，Azure AI Studio 是面向开发者的构建平台，提供 API、微调与部署能力。

没有编程经验能用吗？基本试用可以，但构建生产级应用需要开发与运维基础。
