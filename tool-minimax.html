🧭 工具简介

MiniMax（稀宇科技）是总部位于上海的 AI 大模型公司，成立于 2021 年底，属于外界常说的"AI 大模型六小龙"之一。公司自研多模态大模型，面向全球市场提供模型 API 与消费级产品，其中以视频生成见长的海螺AI（Hailuo AI）知名度最高。2026 年 1 月 9 日，MiniMax 正式在香港联交所主板挂牌上市（股票代码 0100.HK），募资金额约 48.2 亿港元，据公开报道创下当时全球 AI 大模型公司 IPO 规模的新纪录，上市首日涨幅一度超过一倍。

MiniMax 解决的问题很直接：让普通用户通过文字或图片就能生成画面连贯、运镜自然的短视频，也让开发者能以相对低的成本在应用里接入多模态能力。2024 年 9 月公司曾公布其大模型日均交互量达到 30 亿次、每日处理 3 万亿 token，视频产品此后长期位列全球 AI 视频工具榜单前列，是国产 AI 视频赛道最具代表性的玩家之一。

⚙️ 核心功能

视频生成（Hailuo 系列）：海螺AI 的核心能力是文生视频与图生视频。2025 年 6 月 18 日，MiniMax 发布新一代 Hailuo 视频模型更新，新增 1080p 原生视频创作场景，并在海螺视频的 Web 端、App 以及开放平台 API 中同步上线。用户可以输入一段中文描述，让模型生成带有镜头运动、主体动作和场景变化的视频片段。

首尾帧与指令控制：在 API 侧，Hailuo 模型支持首尾帧技术——用户分别指定起始画面和结束画面，模型自动补全中间的动态过渡，适合需要精确控制镜头起止的创作场景。官方强调模型能理解超出图片内容的文本指令，实现"所写即所拍"，即复杂的分镜描述可以被拆解并还原到画面中。

多模态对话与创作：海螺AI 应用内还提供文本对话、图片生成等能力，底层由 MiniMax 自研的 abab / MiniMax-01 系列大模型驱动，中文理解和生成质量是其主要优势。开发者也可通过开放平台调用对话、语音、视频等多类模型接口。

开源与生态：MiniMax 曾以开源形式发布其部分大模型，供社区自部署研究；同时通过火山引擎之外的多个云平台和海外渠道分发模型能力，服务对象覆盖内容创作者、营销团队与出海应用开发者。

在创作者社区的公开反馈中，海螺视频的镜头运动连贯性与主体一致性评价较高，中文长提示词可以直接输入而无需先翻译成英文，这对国内用户是实打实的便利。模型能力也持续以版本更新的方式迭代，例如 2025 年 9 月起通过开放平台 API 通道补充了首尾帧生成能力，让专业创作者能够精确控制镜头的起止画面，创作粒度更细。综合来看，MiniMax 走的是一条"消费级产品 + 开放平台"双轮驱动的路线，既保证普通用户有顺手的产品可用，也向开发者提供了完整的接入通道。

🖥️ 上手体验

首次使用海螺AI，访问官网或用手机号注册后即可进入主界面。视频创作入口通常位于"海螺视频"板块：在输入框里写下画面描述，例如主体、场景、光线、镜头运动，然后选择画面比例和时长，点击生成即可。生成过程一般需要等待几十秒到数分钟，完成后可以直接预览和下载。

常用的操作路径还包括：在"灵感"或社区板块浏览其他用户的成品与提示词，一键套用参考；对不满意的结果修改提示词重新生成，或利用首尾帧功能固定起止画面。对于需要批量产出的用户，可以在开放平台创建 API Key，按官方文档调用视频生成接口，并把结果接入自己的业务流程。需要留意的是，1080p、更长时长等规格通常对应更高的会员档位或 API 费用，免费额度只能体验基础生成。

对于团队用户，开放平台提供用量统计、余额管理与调用日志，便于控制成本；个人用户则可以在"创作记录"中管理历史生成，把满意的作品收藏归档。如果你是第一次接触 AI 视频，建议先从免费版开始，用简单的静态场景描述熟悉模型的输出习惯，再逐步尝试运镜、转场和人物动作等复杂指令，这样更容易判断提示词与成片之间的对应关系。

💰 价格方案

海螺AI 个人端采用订阅制：免费版提供每日基础额度，付费会员分为多个档位，不同档位对应分辨率、时长和生成次数上限。2025 年 6 月会员价格调整后，最高档"至臻版"年费为 10788 元，曾引发用户关于定价过高的讨论，公司回应称这已是行业底价。开发者侧按 API 实际用量计费，官方长期宣传其视频生成 API 价格处于行业低位。

档位价格说明
免费版0 元每日有限生成额度，适合尝鲜
会员版（多档）按月/按年订阅更高分辨率与时长，最高档年费 10788 元（2025 年 6 月调整）
开放平台 API按 token / 视频时长计费面向开发者，官方称行业低价

具体档位与价格以官网实时信息为准。

👍 优点与局限

优点：视频生成质量与中文语义理解在同类产品中处于第一梯队；产品线完整，从对话、图像到视频均有覆盖；API 定价激进，对开发者友好；公司已上市，产品长期维护有保障。

局限：高端会员年费接近万元，个人重度用户的成本不低；生成结果存在随机性，复杂场景往往需要多次"抽卡"；部分高级规格与功能仅对高价位档开放，免费用户可体验的范围有限。

🎯 适合人群

短视频创作者与自媒体运营者，需要快速产出画面素材；广告与营销团队，用 AI 视频做创意预演和批量测试；影视与动画行业从业者，在前期做概念验证和分镜预览；以及需要在应用或网站中接入视频生成能力的开发者与产品团队。
