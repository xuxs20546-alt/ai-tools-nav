🧩 核心功能

高质量文生图（Text-to-Image）：FLUX Pro 系列是 Black Forest Labs（bfl.ai）推出的商用级图像生成模型。FLUX.1 系列于 2024 年 8 月发布，官方随后迭代出 FLUX1.1 [pro] 等版本，擅长生成细节丰富、构图准确的写实与风格化图像，在人体结构、复杂场景与文字渲染等难点上表现突出。

图像编辑与重绘：借助 FLUX 系列模型与官方 API，可以完成局部重绘、画布扩展（outpainting）、按提示词修改图像内容等操作，适合电商主图、广告素材等需要多轮调整的生产工作流。

高速推理与 API 接入：FLUX1.1 [pro] 在推理速度上做了明显优化，官方采用按张计费的即付即用模式；同时可以通过 DeepInfra、Azure AI Foundry 等平台以 API 形式调用，方便开发者和团队把图像生成能力集成进自有产品。

开源生态：Black Forest Labs 同时发布可下载权重的研究与开源版本，社区在此基础上衍生出大量微调模型、LoRA 与插件，用户可以在本地或自有 GPU 服务器上部署，兼顾数据隐私与成本控制。

🖥️ 上手体验

普通用户不需要直接接触模型代码：可以在 Replicate、DeepInfra、fal.ai 等第三方推理平台上选择 FLUX 模型，输入提示词即可生成图像；也可以在集成了 FLUX 能力的对话产品（如 xAI 的 Grok 图像生成功能）中直接描述需求。开发者则注册 bfl.ai 获取 API Key，调用 FLUX1.1 [pro] 接口，按张付费。

实际使用中，把提示词写得具体（主体、光线、构图、风格关键词）能显著提升出图质量；FLUX 对英文提示词的理解最好，中文提示词建议先翻译成英文再生成。单张生成耗时通常在几秒到十几秒之间，批量生产时建议先小批量试跑确认风格方向，再放大规模。

❓ 常见问题

Q：FLUX 和 Stable Diffusion 有什么关系？
A：Black Forest Labs 的核心团队由原 Stability AI 研究人员创立，FLUX 是其推出的新一代架构模型，与 Stable Diffusion 没有直接的版本继承关系。

Q：FLUX Pro 有免费试用吗？
A：官方 API 为付费按量计费；部分第三方平台会提供少量免费额度或试用，可关注具体平台的说明。

Q：个人用户怎么用 FLUX？
A：可以通过集成 FLUX 的在线产品、第三方推理平台按张付费使用，或在自有 GPU 上部署开源版本。
