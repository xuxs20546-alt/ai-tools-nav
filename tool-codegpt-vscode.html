📖 工具简介

CodeGPT 是一个 VS Code 扩展插件，定位是"AI 编程的中立聚合层"——不绑定任何单一 AI 模型提供商，让开发者自由选择和切换不同的 AI 模型来辅助编码。通过 CodeGPT 可以在 VS Code 中同时使用 OpenAI 的 GPT-4o、Anthropic 的 Claude、Google 的 Gemini 以及各种开源模型（通过 Ollama/LM Studio 本地部署），用自己的 API key 按需调用。

CodeGPT 提供了代码补全、对话式编程助手、代码解释、单元测试生成和代码审查等功能。独特之处在于"智能路由"机制——可以配置日常补全使用便宜的 GPT-4o-mini，复杂架构分析使用 Claude 3.5 Sonnet，大量代码上下文分析使用 Gemini 1.5 Pro。这种精细化调度让开发者在保证代码质量的同时将 API 成本降到最低。基础版免费，Pro 版 $9.99/月。

✨ 优劣势分析

👍 优点

  • 模型选择自由度最高：不锁定任何供应商，支持接入几乎所有主流 AI 模型及本地部署开源模型
  • 成本可控：按自己 API key 调用，可选用便宜模型处理简单任务、昂贵模型处理复杂任务
  • 智能路由：配置任务到模型映射规则，AI 自动选择最合适模型实现性价比最大化
  • 隐私友好：使用自己 API key 或本地模型，代码不发送到第三方服务器

👎 不足

  • 需自行管理 API key：不具备技术背景的用户可能觉得配置繁琐
  • 补全速度取决于模型：本地模型可能较慢，云端模型依赖网络质量
  • 功能深度不如原生 AI IDE：相比 Cursor Composer 缺少高级自动化编排

🎯 适用场景

  • 成本敏感型团队 — 10 个开发者使用低成本 GPT-4o-mini API key 日常补全，月度总成本不到 $30
  • 本地模型优先企业 — 安全合规要求代码不出本地网络，接入 Ollama 部署本地开源模型
  • 多模型对比实验 — 想比较不同模型在特定编程任务上的表现，切换模型像换频道一样简单

💡 使用建议

  • 配置智能路由规则：建立补全→GPT-4o-mini、解释→Claude、重构→GPT-4o 的映射
  • 本地模型做缓存：使用 CodeGPT + Ollama + CodeLlama 处理日常补全
  • 定期审查 API 用量：查看每个模型的 token 消耗趋势，发现异常及时调整配置
