工具简介

agent-qa 是 vostride 的自然语言测试工具，支持 Web、Android 与 iOS。开发者和 QA 团队可以通过 CLI 描述测试目标，也可以通过 MCP 将测试能力接入编码智能体工作流。

核心能力

  • 自然语言测试：用自然语言描述网页和移动应用的测试目标。
  • memidex 持久记忆：保存可复用的测试知识和经验。
  • 经验证的自我改进：在后续测试中复用已经验证的经验。
  • CLI 与 MCP：支持命令行使用及编码智能体调用。

适用场景

适合网页和移动应用的功能验证、开发过程中的重复测试，以及编码智能体工作流中的质量检查。

使用与费用

CLI 可免费使用；配置的 AI 模型服务可能产生费用。开始使用前，请按官方文档配置模型访问、项目以及相应的浏览器或移动端测试环境。
