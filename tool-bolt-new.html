工具简介

Bolt.new 是 StackBlitz 于 2024 年 10 月推出的 AI 全栈开发工具，用户在浏览器里用一句自然语言描述需求，就能生成一个可以运行的完整 Web 应用。它依托 StackBlitz 自研的 WebContainers 技术，把 Node.js 等开发环境直接跑在浏览器里，AI 生成的代码可以即时预览、编辑、运行命令甚至部署上线，无需在本地安装任何环境。发布后迅速成为现象级产品，也让"用提示词开发完整应用"从演示变成日常工具。其背后的 WebContainers 技术原本就用于 StackBlitz 的在线开发环境，与生成式 AI 结合后，第一次让"AI 生成可运行应用"变得人人可用。2025 年起产品统一以 Bolt 品牌对外，面向开发者和非技术用户同时提供服务。

核心功能

第一是提示词生成应用。输入"做一个带登录功能的待办事项应用"之类的需求，Bolt 会生成包括前端、后端、数据库在内的完整项目结构，并直接运行在浏览器预览窗口中。

第二是对话式迭代。生成后可以继续用对话修改：调整样式、增加功能、修复报错，AI 会直接编辑代码并刷新预览，整个流程不需要打开代码编辑器。修改指令越具体，改动越精准，例如描述"把按钮改成圆角并加阴影"比"改好看一点"有效得多。

第三是文件与终端访问。用户可以在界面中查看和修改项目文件，也能在集成的终端里执行 npm 命令等操作，兼顾了"零门槛生成"和"开发者可控"两个方向。

第四是一键部署与分享。项目可以部署到 Netlify、Cloudflare 等平台，或生成一个可分享的链接，方便把原型直接发给客户、同事验收。

第五是模板与集成。支持从 StackBlitz 模板启动项目，也提供 GitHub 集成、Figma 设计稿导入等能力，让既有工作流可以衔接。

上手体验

打开 bolt.new 首页就是一个提示词输入框，登录后直接描述想要的应用，几十秒内即可看到第一版运行效果，这一"开箱即用"的体验是它最打动人的地方。

典型使用路径是：输入需求 → 等待生成 → 在预览中试用 → 用对话提出修改意见 → 部署或导出代码。对非技术用户，做完第二步就可以把链接发给别人演示；对开发者，则通常会把生成的项目拉到本地继续深入开发。

需要留意的是用量消耗：Bolt 按 token 计费，复杂的对话和大型项目会消耗较多额度，免费额度有限，重度使用基本需要订阅。另外生成结果的工程质量依赖提示词的清晰度，把需求写具体（页面、交互、技术栈）能显著提高产出质量。另一个实用技巧是把需求拆成多个小对话而不是一次塞进一个大提示词：先让 AI 搭好页面骨架，再逐块补充功能与样式，生成质量通常更稳定，token 消耗也更容易控制。

优点与局限

优点：浏览器内全流程运行，零安装零配置，上手门槛极低；从生成到部署的闭环完整，非常适合快速验证想法和做原型；对话式修改让非技术用户也能参与产品迭代；生成的代码可导出，不会被平台锁定。

局限：token 计费模式下成本不易预估，复杂项目消耗快；生成代码对超大规模或高并发场景支持有限，生产级系统仍需人工重构；对网络环境要求较高，浏览器内运行大型项目时性能受设备影响；国内直接访问体验不稳定。

适合人群

  • 想快速验证产品想法、做原型的设计师与产品经理；
  • 没有编程背景但需要搭建网站或小应用的非技术用户；
  • 希望用 AI 提升全栈开发效率的独立开发者；
  • 教学、黑客松等需要快速出成果的场景。

常见问题

Bolt 和 Cursor 是什么关系？ 没有关系，Bolt 来自 StackBlitz，主打浏览器内生成完整应用；Cursor 是独立的 AI 代码编辑器。

免费版够用吗？ 适合体验和轻量原型，token 有限，做正式项目基本需要升级 Pro。

生成的代码能商用吗？ 可以导出到本地继续开发，商用场景建议结合自己的代码审查与测试流程。

需要安装 Node.js 吗？ 不需要，运行环境由 WebContainers 在浏览器内提供。

Bolt 生成的应用适合直接上线吗？ 适合原型和中小规模应用快速上线，但生产级系统建议经过代码审查、测试与安全评估后再部署。
